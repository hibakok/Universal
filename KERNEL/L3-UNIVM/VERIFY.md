## 2. Уровни проверки (SPEC/02; батарея 179/179)

1. Целостность: SHA-256 (лаборатория — реестр SHA lab_verify.py).
2. PE-инварианты SPEC/04: hint-записи на чётных RVA, одна секция,
   обёртка PEG kernel.peg (SPEC/11 п. 6 — константа для WALL-программ).
3. Фикс-пункт воспроизводимости (T-E7-09): сборка kernel.wall
   конвейером wall → enc → brick → pegen (эмуляция, ~93 млн шагов)
   == артефактам байт-в-байт; kernel.b2 == оракулу WALL.
4. Контракт CLI/контейнера (T-E7-10/11): справка/лишний аргумент/
   LONG NAME/OPEN UP/предел шагов (2-й аргумент CLI: приятие
   0..2147483647, отвержение не-цифр/знака/переполнения/третьего
   слова); отказы SIG/VER/MEM/CODE0/LEN/RES/DATA (v1+v2) — в порядке
   оракула parse_up (SPEC/13 п. 4).
5. Диффтест с оракулом UNIVM (T-E7-12/13/15..18, T-E7-32):
   halt-программы (консоль/код возврата), ловушки 1/2 (диагностика
   TRAP/STEPS, код 1), ALU среза 2 (поля-заполнители, обрезки всех
   форматов, точные счётчики шагов, отсутствие ложных ловушек),
   срез 3 — ПАМЯТЬ/УСТРОЙСТВА (RAM: запись/чтение/sext8/нулевой
   старт, невыровненные слова; окно: консоль/резерв/чтение; ловушки
   3/4 — границы, бит 31, заворот; memsize = 0) и срез 4 —
   ПЕРЕХОДЫ (jmp/jnz: петли вперёд/назад, не взят, границы/цели за
   кодом; полный корпус программ T-E7-04..08 — demo/ops/dev) +
   ПРЕДЕЛ ШАГОВ (trap 6: вечные циклы, halt ровно на пределе, сток
   кода на пределе — trap 6, не 2; лимит — 2-й аргумент CLI) ==
   LAB/py/lab_vm.py; детерминизм (T-E7-14). E7.4-2a: контейнер v2 —
   секция данных -> RAM[0:datalen] при загрузке (T-E7-32: печать
   данных, порядок байтов, перезапись кодом, datalen == memsize,
   данные 4196 Б > куска чтения 4096, v2 dataoff=0 == v1; отказы
   LEN/RES/DATA — T-E7-11). E7.4-2b: ALU v1 — опкоды 13..16
   (mul/div/mod/sra, F1) + ловушка 7 (T-E7-33: поля/обрезки,
   деление на ноль — порядок проверок п. 7, точные счётчики,
   eq-проверки полных 64-битных значений, границы путей udivmod
   b = 2^63 / b > 2^63, инвариант деления). E7.4-2c: call/ret —
   опкоды 17..18 (F3/F0) + аппаратный стек вызовов глубины 1024
   (T-E7-34: поля/обрезки, ret на пустом стеке, переполнение 1025-м
   call (STEPS=1024), ret-в-себя, порядок вывода ACB, вложенность
   + LIFO, глубина РОВНО 1024, рекурсия 5! со стеком sp = r13,
   точные счётчики, предел шагов trap 6, порядок проверок — полный
   стек + мусорное поле rd=1 -> ловушка 1, НЕ 5). Приёмка DoD
   этапа 7.2: ВСЕ 18 опкодов ISA v0 исполняются ядром; с E7.4-2c
   исполнена и вся ISA v1 (24 опкода 01..18).

- **E7.4-2b (сессия 56, 2026-11-20):** ALU v1 — опкоды 13..16
  (mul/div/mod/sra, формат F1) + ловушка 7. НОВАЯ ЧАСТЬ
  kernel_self_alu.wall (ветвь V, выделена из kernel_self_vm.wall
  по лимиту 500 строк): К3-V112 udivmod — БЕЗЗНАКОВОЕ деление
  64-битных слов, собранное из простых операций WALL (деление
  WALL знаковое — idiv; беззнаковость: сравнение с переворотом
  знакового бита (x ^ 2^63) >= (y ^ 2^63) знаково; путь b > 2^63
