## 2. Уровни проверки (SPEC/02; батарея 157/157)

1. Целостность: SHA-256 (лаборатория — реестр SHA lab_verify.py).
2. PE-инварианты SPEC/04: hint-записи на чётных RVA, одна секция,
   обёртка PEG kernel.peg (SPEC/11 п. 6 — константа для WALL-программ).
3. Фикс-пункт воспроизводимости (T-E7-09): сборка kernel.wall
   конвейером wall → enc → brick → pegen (эмуляция, ~61 млн шагов)
   == артефактам байт-в-байт; kernel.b2 == оракулу WALL.
4. Контракт CLI/контейнера (T-E7-10/11): справка/лишний аргумент/
   LONG NAME/OPEN UP; отказы SIG/VER/MEM/CODE0/LEN/RES — в порядке
   оракула parse_up (SPEC/13 п. 4).
5. Диффтест с оракулом UNIVM (T-E7-12/13/15): halt-программы (консоль/
   код возврата), ловушки 1/2 (диагностика TRAP/STEPS, код 1) и ALU
   среза 2 (поля-заполнители, обрезки всех форматов, точные счётчики
   шагов, отсутствие ложных ловушек) == LAB/py/lab_vm.py; детерминизм
   (T-E7-14).

## 3. Журнал срезов

- **E7.2-1 (сессия 45, 2026-11-19):** каркас ядра — CLI (skip0/
  read_arg/check_end — один аргумент строго), чтение файла, разбор
  контейнера .UP (rd32 + read_up; беззнаковое сравнение memsize по
  старшему dword), цикл интерпретатора с halt (op_halt/fail_trap +
  copy_str/out_dec для диагностики «U-L3-UNIVM TRAP=n STEPS=s»).
  Артефакты впервые зафиксированы; корпус среза 1 — зелёный.
  Дефектов не найдено (первая сборка совпала с оракулом WALL
  байт-в-байт и прошла весь корпус с первого прогона).
- **E7.2-2 (сессия 46, 2026-11-19):** регистры + ALU — глобальный
  массив regs[16] (r0 равноправен), кирпичи K3-V101..V111 (const с
  sext32 через сдвиг imm >> 31 — без литералей > 2^31-1; mov с
  проверкой rb = 0; add/sub/and/or/xor — битовый образ совпадает с
  беззнаковым UNIVM; shl/shr со маской счётчика 63; lt/eq — знаковое
  сравнение WALL == семантика SPEC/12 п. 5); interp: проверка длины
  для ВСЕХ валидных опкодов 01..12 (F1 3 Б / F2+F3 6 Б) — обрезка
  валидного опкода даёт ловушку 2 ДО заглушки (как оракул; в срезе 1
  заглушки не различали). Корпус T-E7-15 (17 случаев) — зелёный с
  первого прогона; артефакты пересобраны (10240 → 16384 Б).
  Попутно НАЙДЕН ДЕФЕКТ №23 wall.exe (pp_pcount — двухсимвольные
  операторы не завершают скан пар индексации; «индекс == индекс» —
  ложный ERR=FORMAT): в op_eq правый операнд взят в скобки
  (прозрачны, вывод тот же); фикс инструмента — отдельный срез
  (журнал — KERNEL/L2-WALL/VERIFY.md §4, №23).
