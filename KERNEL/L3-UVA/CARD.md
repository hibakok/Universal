# Карточка модуля M3-UVA (ассемблер UNIVM)

Паспорт файла: KERNEL/L3-UVA/CARD.md | слой: L3 | роль: карточка модуля.

| Поле | Значение |
|---|---|
| ID модуля | M3-UVA |
| Слой | L3 (ВИРТМАШИНА); исходник — WALL v2 (слой L2, SPEC/11) с разрезом по !include (SPEC/10). Второй модуль слоя L3 (сериал кирпичей 011 — по прецеденту M0-SEED2) |
| Назначение | **Ассемблер .uva -> .UP**: читает текст программы UNIVM (мнемоники SPEC/12 п. 8, директива `.mem`, метки) и собирает контейнер .UP (SPEC/13); выход обязан совпадать с ассемблером оракула `LAB/py/lab_vm.py` (`assemble`) байт-в-байт — правило R8, общие свидетели — якоря T-E7-01. Срез E7.3-1 (каркас): полный конвейер CLI -> чтение -> разбор строк (комментарии `;`, края-разделители, токены) -> `.mem` (одна, до инструкций, 0..64 МиБ) -> инструкция `halt` (F3: `12 00 imm32 LE`) -> запись .UP (заголовок 24 Б + код одним WriteFile); прочие мнемоники и метки — срезы E7.3-2+ (пока `ERR=FORMAT AT=строка`) |
| Вход | командная строка Windows: `uva.exe <вход.uva> <выход.up>` (ровно 2 аргумента; исходник ≤ 65536 байт) |
| Выход | файл .UP v1 (24 + codesize байт). Диагностика: справка `U-L3-UVA CMDS: UVA <SRC.UVA> <OUT.UP>` (код 2 — 0/1/3 аргумента); `ERR=LONG NAME` (3); `ERR=OPEN SRC` (4); `ERR=READ SRC` (5, вкл. отказ распределения буферов); `ERR=FORMAT AT=XXXX` (6 — XXXX ЗАГЛАВНЫЙ hex-номер строки с 1: ошибки разбора, как `AsmError.line` оракула; «нет .mem» — всегда строка 1, как `AsmError(1)` оракула); `ERR=CODE0` (6 — .mem без инструкций, как `make_up` оракула); `ERR=BIG SRC` (7 — исходник > 65536 Б); `ERR=OPEN OUT` (8); `ERR=WRITE OUT` (9) |
| Версия | E7.3-1 (сессия 50) — каркас: CLI + чтение + строки/токены/числа + .mem + halt + запись .UP; диффтест с оракулом на halt-корпусе (17 успехов + 21 отвержение + 3 CODE0) и сквозной круг uva -> kernel.exe |
| Размер | 15360 байт (0x3C00); тело 14681 Б (0x3959); вход 0x1200 (SPEC/11 п. 6) |
| Платформа | Windows x64, консольная подсистема, PE32+ |
| Импорты | kernel32.dll (8): GetStdHandle, WriteFile, ExitProcess, GetCommandLineA, CreateFile2, ReadFile, CloseHandle, GlobalAlloc |
| Самохостинг | артефакты `uva.b2/brick/exe` — ГЕНЕРИРУЕМАЯ сборка из `uva.wall` конвейером инструментов (wall → enc → brick → pegen + uva.peg) под эмуляцией LAB; фикс-пункт воспроизводимости — батарея T-E7-19 (каждый пуш); uva.b2 == оракулу WALL байт-в-байт |

## Формат вызова

```
uva.exe program.uva program.up
```

Аргументы: путь исходника .uva (≤ 127 байт ANSI) + путь выхода .up.
Язык исходника среза 1: строки `[директива | инструкция] [';' комментарий]`,
разделители токенов — пробел/таб/CR/VT/FF/запятая (как `[,\s]+` оракула);
директива `.mem <число>` (0..67108864, одна, до первой инструкции);
инструкция `halt <число>` (imm32: −2147483648..4294967295, dec со знаком
или 0x-hex). Строки из одних разделителей пусты (фикс оракула E7.3-1).
Ошибки операндов — на проходе 2 (как у оракула: счёт операндов, потом
число). Диффтест: `LAB/py/lab_t_uva.py` (секция 15 батареи, T-E7-19..24).

## Регистровые соглашения модуля

Канон WALL (SPEC/11 п. 5): rbp-кадры, ARGREG rcx/rdx/r8/r9, рабочие
r10/r11. Состояние ассемблера — глобали образа (BYTECODE.md §3):
srcbuf/srclen (исходник в куче), outbuf (выход: заголовок + код),
memsize (−1 = нет .mem), pc (длина кода), lpos/lln/lna/lne (итератор
строк), tcnt/tstart[12]/tend[12] (токены текущей строки), nval
(разобранное число).

## Данные образа

- строки s_use..s_halt (14 литералов, CRLF; s_hexd — hex-цифры,
  s_up01 = 'UP01', s_dotmem/s_halt — ключевые слова среза);
- глобальные массивы: arg1[64]/arg2[64]/w1[64]/w2[64] (CLI),
  tstart[12]/tend[12] (позиции токенов в srcbuf), fmtbuf[48]
  (строка ERR=FORMAT);
- исходник — в куче GlobalAlloc(0, 65537); выход — GlobalAlloc(0, 65560)
  (24 + максимум кода 65536: строка-инструкция ≥ 6 байт исходника,
  отношение код/исходник ≤ 1).

## Ограничения (снять в следующих срезах)

- Известная мнемоника — только `halt`; остальные 17 мнемоник ISA v0
  и метки переходов — срезы E7.3-2..4 (до них — ERR=FORMAT AT=строка;
  оракул такие программы собирает — диффтест на них не входит
  в корпус среза 1).
- Исходник ≤ 65536 байт, строка-литерал ошибки ≤ 0xFFFF (границы
  тестированы T-E7-20); код ≤ 65536 байт (ёмкость outbuf).
- Таблица меток (срез 2+): имена ≤ 63 байт, ёмкость будет задана
  срезом (фиксируется в CARD следующего среза).
- Числа .mem/halt — только imm32-диапазон оракула (−2^31..2^32−1);
  операнды памяти `rA+смещ` — срез 3 (парсер parse_num переиспользуется).

## Примеры

```
cmd -> KERNEL\L3-UVA\uva.exe
Вывод:   U-L3-UVA CMDS: UVA <SRC.UVA> <OUT.UP>   (40 байт, CRLF)
Код:     2

uva.exe a.uva b.up      (a.uva: ".mem 8" + "halt 42")
Вывод:   (пусто); b.up: 30 байт (заголовок + 12 00 2A 00 00 00)
Код:     0

kernel.exe b.up         (сквозной круг — T-E7-24)
Код:     42

uva.exe a.uva b.up      (a.uva: "halt 0" без .mem)
Вывод:   U-L3-UVA ERR=FORMAT AT=0001
Код:     6

uva.exe a.uva b.up      (a.uva: ".mem 8" без инструкций)
Вывод:   U-L3-UVA ERR=CODE0
Код:     6

uva.exe a.uva b.up      (a.uva: ".mem 8" + "halt 1" + "halt 2 3")
Вывод:   U-L3-UVA ERR=FORMAT AT=0003   (лишний операнд — проход 2)
Код:     6
```
