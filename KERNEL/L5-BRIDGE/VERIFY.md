## 2. Уровни проверки (SPEC/02; батарея 242/242, группы 1/2/3/4/5)

1. Целостность: SHA-256 (лаборатория — реестр SHA lab_verify.py).
2. PE-инварианты SPEC/04 (вход 0x1200 — легальное отклонение

3. Фикс-пункт воспроизводимости (T-E9-17): сборка bridge.wall

   (прецедент T-E6-49a)) == артефактам байт-в-байт; bridge.b2 ==
   оракулу WALL.
4. Контракт CLI каркаса (T-E9-19): справка (нет аргументов / два /
   четвёртый), LONG NAME, OPEN EXE, BIG EXE (256 КиБ); семейные

   NumberOfSections/Magic/ImageBase/Subsystem/имя секции/
   SizeOfImage/SizeOfHeaders/вход вне секции/файл короче raw/
   нулевой код/заглушка/игла/пробел в имени/DLL-имя/hint нечётный/

   выжившая инструкция пересекает VirtualSize) и длина тела >

   ЛЕГАЛЬНЫЕ отклонения — вход 0x1100 (внутри секции) и регистр
   DLL-имени: успех с фактами == оракулу (диффтест семейства на
   мутантах).

6. Синтетика спуска (T-E9-21): рукотворный образ (префикс импортов
