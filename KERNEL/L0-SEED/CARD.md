# Карточка модуля M0-SEED (семя)

Паспорт файла: KERNEL/L0-SEED/CARD.md | слой: L0 | роль: карточка модуля.

| Поле | Значение |
|---|---|
| ID модуля | M0-SEED |
| Слой | L0 (МАШИНА) |
| Назначение | Первая жизнь системы: EXE, написанный вручную байтами |
| Вход | нет (запуск двойным щелчком или из консоли) |
| Выход | строка `U-L0-SEED OK IMAGE=0x00002000` + CRLF в stdout; код возврата 0 |
| Размер | 1024 байта (0x400) |
| Платформа | Windows x64, консольная подсистема, PE32+ |

## Состав (что читать для работы с модулем)

| Файл | Назначение |
|---|---|
| `seed.hex` | тело секции в формате ATOM v1, телесная форма (истина) |
| `seed.peg` | управляющий файл обёртки (PEG v1, SPEC/07) |
| `seed.exe` | материализация исходника (байт-в-байт) |
| `BYTECODE.md` | байт-за-байтом разбор: заголовки, код, данные, импорты |
| `VERIFY.md` | SHA-256, инструкции по проверке подлинности и запуску |

## Кирпичи модуля (карточки — MAP/METHODS.md)

```
Поток исполнения:
  K0-X001 prepare_stack
  K0-S001 get_image_base
  K0-S002 read_sizeofimage      (использует K0-S001)
  K0-H001 hex32_to_ascii8       (использует K0-S002)
  K0-P001 write_stdout          (использует K0-D001)
  K0-X002 exit_ok
Данные:
  K0-D001 данные семени (строка, цифры, written)
  K0-D002 таблица импортов (kernel32.dll)
```

## Что семя доказывает

1. Возможность писать EXE вручную, байт за байтом, без всяких тулчейнов.
2. Позиционную независимость: вся адресация rip-относительная.
3. Самопознание: программа читает собственный PE-заголовок и печатает
   SizeOfImage — число в выводе сверяется с заголовком (тест T-M0-04).
4. Воспроизводимость: листинг -> байты -> хэш -> запуск образуют
   проверяемую цепочку.

## Ограничения (снять в следующих этапах)

- Материализация байтов выполняется вне репозитория (до HEXGEN, этап E3).
- Смещения rip-ссылок считаются вручную (до BRICK, этап E5).
- Поддерживается только вывод в консоль; ввода нет (этапы E1-E2).
