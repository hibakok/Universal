# Проверка семени M0-SEED

Паспорт файла: KERNEL/L0-SEED/VERIFY.md | слой: L0 | роль: инструкция проверки.

## Паспорт артефакта

| Свойство | Значение |
|---|---|
| Файл | `KERNEL/L0-SEED/seed.exe` |
| Размер | 1024 байта |
| SHA-256 | `615D3292CCDD08664F7ACFCF9EF39E55F37443D1BF5A5F3E40D1CC796E64DBDF` |
| Тип | PE32+ (консоль, x86-64), 1 секция, импорт kernel32.dll |
| Исходник | `seed.hex` (формат ATOM v1) — полный байтовый листинг |

## Проверка 1: подлинность (хэш)

В командной строке Windows (cmd или PowerShell) в папке с файлом:

```
certutil -hashfile seed.exe SHA256
```

Вывод должен совпасть с SHA-256 из таблицы выше (регистр букв не важен).

## Проверка 2: запуск

```
seed.exe
```

Ожидаемый вывод (31 байт + перевод строки):

```
U-L0-SEED OK IMAGE=0x00002000
```

Число 00002000 — это SizeOfImage из собственного PE-заголовка программы
(поле по смещению 0xD0 образа, см. `BYTECODE.md`). Вывод не совпал —
файл повреждён или изменён.

## Проверка 3: код возврата

```
seed.exe
echo %errorlevel%
```

Должно быть выведено `0`.

## Проверка 4: соответствие листингу

Открыть `seed.hex` и `BYTECODE.md`; сверить контрольные байты из
`TESTS/T-L0-SEED.md` (тест T-M0-05) в любом hex-просмотрщике.
До этапа E3 (HEXGEN) полная автоматическая сверка выполняется вручную
по контрольным точкам.

## Замечания

- Файл не имеет цифровой подписи: SmartScreen/антивирус могут спросить
  подтверждение. Каждый байт файла задокументирован в `BYTECODE.md`.
- Программа не читает и не пишет файлы, не обращается к сети,
  не изменяет систему: только вывод в консоль и завершение.
- Запуск возможен на Windows 7+ x64 и под Wine (подсистема консоли).

## Журнал верификации (заполняется при каждом изменении)

| Дата | Кто | Уровни проверки | Результат |
|---|---|---|---|
| Этап E0 | ИИ (GLM) | PE-разбор (34 поля) + дизассемблер (28 инструкций) + эмуляция (82 шага) | все зелёные |
