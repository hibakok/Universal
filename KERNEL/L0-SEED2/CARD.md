# Карточка модуля M0-SEED2 (семя-2: командная строка)

Паспорт файла: KERNEL/L0-SEED2/CARD.md | слой: L0 | роль: карточка модуля.

| Поле | Значение |
|---|---|
| ID модуля | M0-SEED2 |
| Слой | L0 (МАШИНА) |
| Назначение | Первый интерактивный инструмент: чтение командной строки и печать полей собственного PE-заголовка |
| Вход | командная строка Windows: `seed2.exe <команда> [хвост]` |
| Выход | строка результата в stdout + CRLF; код возврата 0 (успех) или 2 (неизвестная команда) |
| Размер | 2048 байта (0x800) |
| Платформа | Windows x64, консольная подсистема, PE32+ |
| Импорты | kernel32.dll: GetStdHandle, WriteFile, ExitProcess, GetCommandLineA |

## Команды

| Команда | Действие | Вывод (эталон) |
|---|---|---|
| `entry` | AddressOfEntryPoint (PE+0x28) | `U-L0-SEED2 ENTRY=0x00001000` |
| `image` | SizeOfImage (PE+0x50) | `U-L0-SEED2 IMAGE=0x00002000` |
| `align` | SectionAlignment (PE+0x38) | `U-L0-SEED2 ALIGN=0x00001000` |
| `sect` | NumberOfSections (PE+0x06, слово) | `U-L0-SEED2 SECT=0x00000001` |
| `args` | эхо остатка командной строки | `U-L0-SEED2 ARGS: <хвост>` |
| — (пусто) | справка | `U-L0-SEED2 CMDS: ENTRY IMAGE ALIGN SECT ARGS` |
| иное слово | справка + код 2 | та же справка |

Команды различают регистр (только строчные). Разделители аргументов —
пробел и табуляция; путь argv[0] берётся в кавычках или без.

## Кирпичи модуля (карточки — MAP/METHODS.md)

```
Поток исполнения:
  K0-X011 prepare_stack
  K0-S011 get_image_base
  K0-C001 get_cmdline          (новое: GetCommandLineA)
  K0-C002 skip_argv0           (новое: разбор argv[0] с кавычками)
  K0-C003 read_word            (новое)
  K0-C004 find_command         (новое: поиск в таблице команд)
  K0-G001 dispatch             (новое: выбор действия по записи)
  K0-S012 get_pe_base          (новое: адрес PE-сигнатуры)
  K0-P012 print_field_line     (новое: строка поля + hex-поле)
  K0-A001 echo_args            (новое: эхо хвоста)
  K0-C005 count_tail           (новое: длина хвоста до NUL)
  K0-U001 print_usage          (новое: справка)
  K0-X012 exit_code            (код возврата из ECX)
Подпрограммы (перенесены из M0-SEED, см. примечание):
  K0-H011 hex32_to_ascii8      (реинкарнация K0-H001)
  K0-P011 print_line           (реинкарнация K0-P001)
Данные:
  K0-D011 строки вывода
  K0-D012 таблица команд (5 × 16 байт)
  K0-D013 служебные данные (цифры, пробел, CRLF, hstdout, written)
  K0-D014 таблица импортов (+GetCommandLineA)
```

## Примечание о реинкарнациях (важно для реестра)

До этапа E5 (BRICK) физическое разделение кода между образами
невозможно: каждый EXE самодостаточен. Проверенный кирпич переносится
в новый образ копией байтов и получает новый K-ID со ссылкой на
прародителя в поле «Функция» карточки. Это осознанное временное
дублирование, а не нарушение R6 (дублируется артефакт, не карточка).

## Что M0-SEED2 доказывает

1. Чтение ввода: командная строка входит в наш мир (ветвь C).
2. Табличное программирование: поведение задаётся данными (K0-D012),
   а не кодом — добавление команды = запись в таблице + строка.
3. Динамическое самопознание: поля читаются через e_lfanew, образ
   не зависит от конкретного e_lfanew/ базы загрузки.
4. Дисциплина волатильных регистров Win64 (урок rcx → r14).
5. Размер 2048 байт — в пределах лимита этапа (2 КБ, DoD E1).

## Ограничения (снять в следующих этапах)

- Слова команд до 7 символов (ширина записи 8 с NUL).
- Хвост `args` печатается одним куском, без разбора на слова (E1+).
- Нет файлового ввода-вывода (этап E2, HXDUMP).
