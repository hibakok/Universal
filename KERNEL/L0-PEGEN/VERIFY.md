Паспорт файла: KERNEL/L0-PEGEN/VERIFY.md | слой: L0 | роль: инструкция проверки.

| Свойство | Значение |

| SHA-256 | `CB526F1AD57B602EA2544C86B2AC324FC3E02F6B4987ECF9D6122F4879420D2C` |

## Проверка 1: подлинность (хэш)

```
certutil -hashfile pegen.exe SHA256
```

Должно совпасть с SHA-256 из таблицы выше.

## Проверка 2: справка

```
pegen.exe
```

Ожидаемый вывод (57 байт + CRLF): `U-L0-PEGEN CMDS: PEGEN <IMAGE.BIN> <CTRL.PEG> <OUT.EXE>`
Код возврата: 2.

## Проверка 3: коды возврата

Таблица кодов — SPEC/07 (2..11). Каждый код воспроизводится сценариями
тест-плана `TESTS/T-L0-PEGEN.md` (T-M5-07..14).

## Проверка 4: круги сборки (главная)

```
Из папки KERNEL:
  L0-HEXGEN\hexgen.exe L0-SEED\seed.hex t_body.bin
  L0-PEGEN\pegen.exe t_body.bin L0-SEED\seed.peg t_seed.exe
  fc /b t_seed.exe L0-SEED\seed.exe        -> различий нет

  (аналогично seed2 / hxdump / hexgen)

Самосборка:
  L0-HEXGEN\hexgen.exe L0-PEGEN\pegen.hex t_pb.bin
  L0-PEGEN\pegen.exe t_pb.bin L0-PEGEN\pegen.peg t_pegen.exe
  fc /b t_pegen.exe L0-PEGEN\pegen.exe     -> различий нет
```

## Этап E4a: исправление дескриптора импорта

**Дефект (пойман эмуляцией E5):** описатель импорта IDT был записан 16
байтами вместо 20 — отсутствовал нулевой ForwarderChain. Поля съехали:
имя DLL указывало на мусор (RVA 0x1C84 = слот IAT), FirstThunk = 0. Такой
образ не загрузился бы реальным загрузчиком Windows. Эмуляция E4 пропустила
дефект: заглушки Win32 разрешали импорты по позиции, а не по таблице.

**Исправление:** 4 нулевых байта добавлены в дескриптор; таблицы IAT/INT,
имя DLL и hint-записи сдвинуты на +4 (RVA пересчитаны); все rip-смещения
call [rip+IAT] увеличены на 4; pegen.peg: !iat 1C88 40, !bss 20402;
тело 0xD7A. Инварианты SPEC/04 сохранены; все круги E4 и самосборка —
зелёные.

## Пойманные ошибки ручной сборки (все — уровнем 3, эмуляция)

Уроки E4 (дизассемблер пропустил все: кодировки были валидны, но неверны):

1. Направление `89 /r` (повтор урока E1): `mov rsi,rdi` собран как
   `48 89 F7` = mov rdi,rsi.
2. REX-биты (ШЕСТЬ ошибок одного класса): `mov r13,r8` без REX.B
   (4C→4D); `add r8,rbx` — R вместо B (4C 01 D8→49); `add r11,rax` —
   лишний R (4D→49); `movzx eax,[rsi+r10]` — B вместо X (41→42, ×2);
   `mov r8,[r11]` — WB вместо WRB (49→4D); `lea rsi,[rsi+r10]` — WB
   вместо WX (49→4A). Правило: REX = 0100 WRXB (W-вес 8, R-4, X-2, B-1).
3. Знакорасширение imm8 в форме `83 /7`: `cmp rdx,0x80` собран как
   `48 83 FA 80` = cmp rdx,−0x80 → цикл дозаписи заглушки не завершался
   (запись за пределы секции). Заменено на 32-битное `81 FA 80 00 00 00`.
4. Знак в align_up: `add eax,ecx` при ecx=−a давал v−a вместо v+a−1
   (длина дополнения = 0xFFFFFC40). Исправлено на lea eax,[rax+rcx-1].
5. Потеря инструкций при реинкарнации: в skip_argv0 пропущены
   `inc rdi; jmp sa_start` (цикл посимвольного пропуска argv0) —
   первым аргументом становилось имя самой программы.
6. Забыт `add rdi,0x40` в build_stub — заглушка писалась поверх
   DOS-заголовка.
7. Данные: слоты IAT/INT по 7 байт вместо 8; IDT 25 байт вместо 0x28
   (терминатор — полная нулевая запись 20 байт, не 8); записи errtab по
   7 байт вместо 16 (длина/код — dword, не байт).
8. vdesc: в поле перем.2 стоял RVA маркера-нуля вместо самого нуля —
   однозначные директивы требовали второе значение.
9. Спецметка image_base (RVA 0 = тело −0x1000) была перекрыта обычной
   меткой — RBX указывал внутрь кода.

## Пойманные ошибки порта v2 (E9.4-4b-4; уровнем 3, эмуляция)

Мини-ассемблер «компоновки» (LAB/ai/pegen_v2_asm.py) и листинг
(LAB/ai/pegen_v2_code*.py) — 7 классов, все пойманы эмуляцией/round-trip
декодером до или при сборке:

1. modrm без маскирования 3-битных полей для r8-r15 (reg/rm >= 8
   заезжали в mod-биты) — поймано обратным декодированием lab_x86.
2. disp32 считался от фиксированной длины формы (REX-префикс +1 Б,
   C7-форма 10 Б) — цель уезжала на 1..N байт; найдено трассировкой
   эмулятора по ячейкам.
3. `mov` вместо `add` в одной позиции листинга (rcx,rax) — сентинел
   писал по адресу 0; трассировка.
4. Сравнение reg-reg через rip-форму (8 сайтов) — сравнение с мусором
   [rip+0]; ложные отказы; трассировка.
5. Пропуск skip_spaces перед блобами (rsi стоял на пробеле) — «пустой
   блоб»; трассировка.
6. RVA строк v2kwtab без базы +0x1000 — слова не находились, путь
   уходил в v1; трассировка + дамп ячеек.
7. 64-битные чтения 32-битных полей (e_lfanew, datapos) — захват
   соседних байтов, дикие указатели; трассировка.

Вывод: уровень 3 (исполнение) обязателен для каждого образа L0 —
подтверждено в третий раз (E0: 3 ошибки, E1: 5, E2: 6, E3: 3, E4: 9,
E9.4-4b-4: 7 классов, частично по несколько экземпляров).

## Пойманные ошибки подъёма пределов (E9.5-1a; уровнем 3 + разбор
эмиссии; все — в v2-ветви сессии 87, корпус T-M5-18 не покрывал)

1. hex_blob (K0-Q014): предел записи проверялся ДО чтения цифр пары —
   блоб, кончающийся РОВНО на пределе (остров стресс-крафта [0xFF8,
   0x1000) == outbuf+H), ложно отвергался (оракул принимает) — найдено
   трассировкой эмулятора до jae hb_bad. Исправлено: предел — после
   чтения пары цифр.
2. do_hdr (K0-Q016): проверка наложений без сложений (off vs len_j,
   start_j vs len вместо off+len/end_j) — перекрытия на смещениях >= ~64
   пропускались (оракул ловит; мутанты корпуса — только низкие
   смещения) — найдено целевыми пробами «соседние/перекрывающиеся
   спаны на разных смещениях». Исправлено: как в do_sec.
3. pegen_v2_asm.py: mov_rip_i32/cmp_rip_i8 считали disp32 от конца
   ПОЛЯ disp, а не от конца ИНСТРУКЦИИ (+imm32/+imm8 — запись/чтение
   на +4/+1 мимо ячейки; у сессии 87 взаимно компенсировалось —
   поведение было верным, но раскладка ячеек-соседей обязана была
   оставаться неизменной) — найдено сравнением целей декодера с
   таблицей символов. Исправлено: база rip — конец инструкции.
4. Урок ЕЩЁ РАЗ (см. №2 сессии 87): disp зависит от ПОЛНОЙ длины
   формы — теперь и от хвостовых иммедиатов; round-trip контроль
   (имя+длина) не ловит рассинхрон целей — добавленный в E9.5-1a
   контроль фактических целей (сверка [rip+disp] с таблицей символов
   в диагностике LAB/ai/diag_pegen_sites.py) — обязателен при каждой
   новой форме ассемблера.
