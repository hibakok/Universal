# BYTECODE.md — разбор pegen.exe

Паспорт файла: KERNEL/L0-PEGEN/BYTECODE.md | слой: L0 | роль: разбор образа.

Источник истины — `pegen.hex` (телесная форма E4: смещение 0 = RVA 0x1000;
заголовки генерирует pegen по `pegen.peg`, см. SPEC/07). По-инструкционная
деталь (мнемоника + K-ID у каждого байта) — в самом листинге: с E4 BYTECODE
содержит структуру, а не дублирует листинг (причина — лимит 500 строк).

## 1. Заголовки

Генерируются самим pegen из `pegen.peg` (значения — SPEC/07, патч-таблица):
SizeOfImage = 0x22000, VirtualSize = 0x2117C, SizeOfRawData = 0xE00,
DD[1] = RVA 0x1C60 (размер 0x28), DD[12] = RVA 0x1C84 (размер 0x40),
фиксации стека/кучи = 0x4000. Инварианты SPEC/04 выполняются.

## 2. Раскладка внутри .text (RVA = тело + 0x1000)

```

тело 0x07E8  vdesc: 6 описателей × 16 байт {qword перем.1, qword перем.2|0}
тело 0x0848  строки ключевых слов (module, entry, idata, iat, bss, stackcom, heapcom)

тело 0x0C60  IDT: описатель импорта kernel32.dll + нулевой терминатор (0x28)
тело 0x0C84  IAT: 7 адресов + терминатор (заполняет загрузчик; 0x40)

             fname×3 (0x80), modname (0x20), ячейки (0x50),
             filebuf (0x10000), imagebuf (0x10010), zeropad (0x200)
тело 0x2117C конец секции (VirtualSize)
```

## 4. Данные

- **kwtab** (тело 0x7B0): 7 qword — RVA строк ключевых слов; порядок жёсткий:
  module(0), entry(1), idata(2), iat(3), bss(4), stackcom(5), heapcom(6);
  индекс = бит в маске seen (K0-Q011); обязательные — биты 0..3 (маска 0xF).
- **vdesc** (тело 0x7E8): описатели директив-значений в порядке kwtab без
  module: entry {entry, 0}, idata {idata_rva, idata_size},
  iat {iat_rva, iat_size}, bss {bssv, 0}, stackcom {…, 0},
  heapcom {…, 0}. Поле перем.2 = 0 — одно значение (проверка
  K0-Q011: cmp qword [r11+8],0).
- **errtab** (тело 0x09C0): индекс 0 — справка (код 2), 1..9 — ошибки
  (коды 3..11): {RVA строки, длина, код возврата, 0} — по 16 байт.
- **hdr** (тело 0x0A60): копия заголовков seed.exe с обнулёнными
  патч-зонами (список — SPEC/07); фиксации-по-умолчанию 0x1000 в шаблоне
  продублированы явной инициализацией init (K0-G041).
- **Импорты**: расположение как в M0-HEXGEN (7 функций, тот же порядок).

## 5. Инварианты (проверены эмуляцией)

1. `pegen.hex` материализуется в тело 0xD76 байт; SRD = 0xE00; файл
   0x1000 байт; VirtualSize = 0xD76 + bss 0x20406 = 0x2117C.
2. pegen.exe = hexgen(pegen.hex) + pegen(·, pegen.peg) байт-в-байт.
3. Все 5 модулей воспроизводятся конвейером E4 из текстовых исходников
   (ATOM + PEG) без ручных байтов заголовков.
