## Сборка и запуск (Windows, из корня репозитория)

```
KERNEL\L1-SPLICE\splice.exe PROJECTS\banner\banner.uva PROJECTS\banner\banner.flat.uva
KERNEL\L3-UVA\uva.exe PROJECTS\banner\banner.flat.uva PROJECTS\banner\banner.up
KERNEL\L3-UNIVM\kernel.exe PROJECTS\banner\banner.up
```

Эталон вывода — TESTS/T-PROJECTS.md (T-P-01). Сборочные файлы
`banner.flat.uva` / `banner.up` — продукты сборки, в репозиторий не
попадают (.gitignore).

## Что демонстрирует

1. Композиция ЧЕТЫРЁХ ветвей библиотеки (первая четырёхчастная
   программа вне тестов): S — строки из .data, M — построение
   разделителя в RAM, C — печать буфера/CRLF, N — числа u64/i64.
2. Стек-конвенция ветви N в реальной программе: r13 = 4000, слот
   [sp-8, sp) не пересекается с данными программы.
3. Значения шире imm32 грузятся из .data через ldq (2^63 — край i64).
4. Контейнер .UP v2: секция данных (39 Б строк + 2^63).
