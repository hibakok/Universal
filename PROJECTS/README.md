# PROJECTS — внешние программы ядра

Паспорт файла: PROJECTS/README.md | слой: L6 | роль: правила размещения проектов.

## Что здесь будет

Проекты — это программы, исполняемые ядром UNIVERSAL: копия Minecraft,
AGI, утилиты, игры, любые приложения. Пока (этап E0) ядро не исполняет
внешних программ — раздел пуст и ждёт этапа E7 (UNIVM + формат .UP).

## Правила (действуют с момента появления первого проекта)

1. **Один проект = одна папка** `PROJECTS/<имя>/` с обязательным `CARD.md`
   (паспорт: назначение, вход, выход, зависимость от версий ядра).
2. **Ядро неприкосновенно.** Проект не изменяет файлы KERNEL/, SPEC/,
   MAP/ под свои нужды. Общение — только через объявленные интерфейсы
   (системные вызовы UNIVM).
3. **Свои кирпичи — свой реестр**: `PROJECTS/<имя>/METHODS.md` в том же
   формате карточек (SPEC/01). Общие кирпичи библиотеки (L4) переиспользуются
   по ссылке на ID, дублировать их запрещено (правило R6).
4. **Удаление и перемещение** проекта не должны требовать изменений в ядре.
   Если требуют — это дефект архитектуры, а не проекта.
5. Каждый проект сопровождается быстрым тест-планом по `TESTS/POLICY.md`.
