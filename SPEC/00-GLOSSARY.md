# S00. Словарь терминов

Паспорт файла: SPEC/00-GLOSSARY.md | слой: все | роль: термины проекта.

| Термин | Определение |
|---|---|
| **Кирпич** | Минимальный метод: имя + вход + выход + функция. Единица построения. |
| **Ветвь** | Изолированная цепочка кирпичей от простого к сложному. Буква в ID. |
| **Слой** | Уровень абстракции L0..L6. Зависимости только вниз. |
| **Карточка** | Паспорт кирпича по формату SPEC/01-METHOD-CARD.md. |
| **Реестр** | указатель MAP/METHODS.md + карточки в MAP/M<модуль>.md. |
| **ATOM** | Текстовый формат исходников слоя L0: байты со смещениями (SPEC/03). |
| **BRICK** | Будущий символьный формат слоя L1: метки, имена (этап 5). |
| **Семя** | Первый артефакт: `KERNEL/L0-SEED/seed.exe` + его исходники. |
| **Ядро** | Исполняющая система (сейчас — семя; в будущем — UNIVM и инструменты). |
| **Проект** | Внешняя программа, исполняемая ядром; живёт в `PROJECTS/`. |
| **Образ** | PE-файл, загруженный в память загрузчиком Windows. |
| **RVA** | Relative Virtual Address — смещение от начала образа в памяти. |
| **Файловое смещение** | Позиция байта внутри .exe-файла на диске. |
| **PE32+** | Формат 64-разрядных EXE-файлов Windows (наш формат L0). |
| **IAT** | Import Address Table — таблица адресов импортируемых функций. |
| **IDT** | Import Directory Table — описатель импортируемой DLL. |
| **Тень (shadow space)** | 32 байта стека, резервируемые вызывающим под вызовы Win64. |
| **DoD** | Definition of Done — критерии готовности этапа. |
| **Материализация** | Превращение листинга ATOM в бинарный файл (сейчас вручную, с этапа 3 — HEXGEN). |
| **Самохостинг** | Способность инструмента собрать самого себя. |
| **UNIVM** | Будущая универсальная виртуальная машина (слой L3). |
| **.UP** | Будущий формат программ для UNIVM (этап 7). |
| **ID кирпича** | `K{слой}-{ветвь}{номер:3}`. Пример: K0-H001. Вечен и уникален. |
| **ID модуля** | `M{слой}-{имя}`. Пример: M0-SEED. |
| **ID теста** | `T-{ID модуля или кирпича}-{номер}`. Пример: T-M0-02. |

## Регистры x86-64, используемые в проекте

| Регистр | Роль в соглашении проекта (L0) |
|---|---|
| `rax` | результат вызовов Win64; рабочее значение |
| `rcx`, `rdx`, `r8`, `r9` | аргументы 1–4 вызовов Win64 |
| `rbx` | база образа (внутри семени) |
| `rsi` | курсор записи в буфер |
| `rsp` | указатель стека; выравнивание 16; тень 0x20 |
