# S04. Минимальный PE32+ (наш формат EXE)

Паспорт файла: SPEC/04-PE-MINIMAL.md | слой: L0 | роль: спецификация структуры наших EXE.

## Обзор

Минимальный корректный 64-разрядный EXE для Windows: одна секция,
один импорт (kernel32.dll), точка входа в начале секции. Всё, что нужно
загрузчику Windows, — и ни байтом больше.

## Карта файла (значения семени M0-SEED)

```
Смещение  Размер  Содержимое
0x000     0x40    DOS-заголовок (e_lfanew = 0x80)
0x040     0x40    DOS-заглушка (текст, не исполняется)
0x080     0x04    PE-сигнатура "PE\0\0"
0x084     0x14    COFF-заголовок
0x098     0xF0    Опциональный заголовок PE32+ (240 байт)
0x188     0x28    Заголовок секции .text
0x1B0     0x50    нули до выравнивания
0x200     0x200   .text: код + данные + импорты (RVA 0x1000)
Итого:    0x400   (1024 байта)
```

## Ключевые поля (смещение // значение семени)

### DOS-заголовок

| Смещение | Поле | Значение |
|---|---|---|
| 0x00 | сигнатура | `4D 5A` (MZ) |
| 0x3C | e_lfanew | 0x80 |

### COFF-заголовок (от 0x84)

| Поле | Значение |
|---|---|
| Machine | 0x8664 (AMD64) |
| NumberOfSections | 1 |
| SizeOfOptionalHeader | 0xF0 |
| Characteristics | 0x0022 (EXECUTABLE_IMAGE, LARGE_ADDRESS_AWARE) |

### Опциональный заголовок PE32+ (от 0x98; поле // смещение)

| Поле | Смещение | Значение |
|---|---|---|
| Magic | 0x098 | 0x020B |
| AddressOfEntryPoint | 0x0A8 | 0x1000 |
| ImageBase | 0x0B0 | 0x140000000 (байты LE: `00 00 00 40 01 00 00 00`) |
| SectionAlignment | 0x0B8 | 0x1000 |
| FileAlignment | 0x0BC | 0x200 |
| SizeOfImage | 0x0D0 | 0x2000 |
| SizeOfHeaders | 0x0D4 | 0x200 |
| Subsystem | 0x0DC | 3 (консоль) |
| DataDir[1] Import | 0x110 | RVA 0x1100, размер 0x28 |
| DataDir[12] IAT | 0x168 | RVA 0x1130, размер 0x20 |

### Заголовок секции (от 0x188)

| Поле | Значение |
|---|---|
| Name | `.text` |
| VirtualSize | 0x1C0 |
| VirtualAddress | 0x1000 |
| SizeOfRawData | 0x200 |
| PointerToRawData | 0x200 |
| Characteristics | 0xE0000020 (CODE + EXEC + READ + WRITE) |

WRITE необходим: программа пишет в свои данные (hex-поле, written).

## Раскладка внутри .text (RVA // содержимое, значения семени)

```
RVA 0x1000  код (0x7F байт): кирпичи K0-X001..K0-X002
RVA 0x1080  данные: строка вывода, hex-поле, CRLF, таблица цифр, written
RVA 0x1100  IDT: описатель импорта kernel32.dll + терминатор
RVA 0x1130  IAT: 3 адреса функций + терминатор (заполняется загрузчиком)
RVA 0x1160  INT: копия IAT до заполнения (по ней загрузчик ищет имена)
RVA 0x1180  имя "kernel32.dll\0"
RVA 0x1190  hint=0 + "GetStdHandle\0"
RVA 0x11A0  hint=0 + "WriteFile\0"
RVA 0x11AC  hint=0 + "ExitProcess\0"
```

## Образы формата (реестр)

| Образ | Модуль | Файл | Секция (SRD) | VirtualSize | Импорты | DD[1]/DD[12] |
|---|---|---|---|---|---|---|
| seed.exe | M0-SEED | 0x400 (1024 Б) | 0x200 | 0x1C0 | 3 функции | 0x1100 / 0x1130 |
| seed2.exe | M0-SEED2 | 0x800 (2048 Б) | 0x600 | 0x482 | 4 функции | 0x13B0 / 0x13E0 |

Карта конкретного образа (смещения всех его полей) — в его BYTECODE.md.
Инварианты ниже общие для всех образов.

## Инварианты (проверять при каждом изменении)

1. `SizeOfImage` = конец последней секции, округлённый до SectionAlignment.
2. `SizeOfHeaders` = смещение первой секции в файле, кратно FileAlignment.
3. `VirtualSize` >= фактическая длина содержимого секции.
4. `SizeOfRawData` кратно FileAlignment и >= VirtualSize.
5. Точка входа принадлежит секции с EXECUTE.
6. Все RVA в карточках кирпичей соответствуют этой раскладке.
7. Имена функций hint-записей выровнены на чётные RVA (WORD-выравнивание).

## Как загрузчик исполняет наш EXE

1. Читает e_lfanew -> находит PE-сигнатуру.
2. Проверяет Machine/Magic/Subsystem.
3. Отображает секции по VirtualAddress с округлением до SectionAlignment.
4. Обходит IDT: грузит kernel32.dll, по INT находит имена функций,
   вписывает их адреса в IAT.
5. Передаёт управление на AddressOfEntryPoint (RSP%16==8, наверху —
   адрес возврата в kernel32).
