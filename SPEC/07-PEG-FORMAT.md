# S07. Формат PEG v1 (управляющий файл обёртки)

Паспорт файла: SPEC/07-PEG-FORMAT.md | слой: L0 | роль: спецификация PEGEN и PEG.

## Назначение

PEGEN — обёртка образов: превращает бинарное тело секции (выход HEXGEN)
в готовый EXE, генерируя PE-заголовки по шаблону `SPEC/04-PE-MINIMAL.md`.
С этапа E4 ручное сопровождение заголовков прекращается: листинг ATOM
покрывает только секцию (телесная форма, см. `SPEC/03-ATOM-FORMAT.md`),
а всё, что было в заголовках, задаётся директивами PEG-файла.

## Формат вызова

```
pegen.exe <image.bin> <ctrl.peg> <out.exe>
```

Все три аргумента обязательны. `image.bin` — тело секции (обычно выход
`hexgen.exe`); `ctrl.peg` — управляющий файл (настоящая спецификация);
`out.exe` — создаётся заново (CREATE_ALWAYS).

## Грамматика PEG v1

```
файл     := строка*
строка   := пустая | комментарий | директива
комментарий := ';' любой-текст
директива:= '!' имя [значение [значение]]
имя      := строчные латинские буквы (module, entry, idata, iat, bss,
            stackcom, heapcom)
значение := 1..8 ЗАГЛАВНЫХ шестнадцатеричных цифр (0-9A-F), 32 бита
```

Разделители значений — пробелы/табуляции. CR перед LF допускается.
Директивы можно записывать в любом порядке; повтор директивы — побеждает
последняя (не ошибка).

## Директивы

| Директива | Значения | Статус | Назначение |
|---|---|---|---|
| `!module <имя>` | имя 1..31 байт | обязательна | имя модуля для DOS-заглушки |
| `!entry <rva>` | 1 значение | обязательна | RVA точки входа (обычно 1000) |
| `!idata <rva> <размер>` | 2 значения | обязательна | каталог импорта DD[1] |
| `!iat <rva> <размер>` | 2 значения | обязательна | каталог IAT DD[12] |
| `!bss <n>` | 1 значение | опциональна | виртуальные нули в хвосте секции (по умолчанию 0) |
| `!stackcom <n>` | 1 значение | опциональна | фиксация стека (по умолчанию 1000) |
| `!heapcom <n>` | 1 значение | опциональна | фиксация кучи (по умолчанию 1000) |

Резерв стека/кучи фиксирован шаблоном (1 МиБ). Прочие поля заголовков
константны (см. «Патчи» ниже); их изменение — расширение PEG v2.

## Вычисляемые поля заголовка

Пусть `imgsize` — размер image.bin, `vsize = imgsize + bss`,
`align(x, a) = (x + a − 1) & ~(a − 1)`:

| Поле заголовка | Смещение | Значение |
|---|---|---|
| DOS-заглушка | 0x040 | «Universal L0 `<module>`. No DOS support.\r\n$», нули до 0x80 |
| SizeOfCode | 0x09C | `align(imgsize, 0x200)` |
| AddressOfEntryPoint | 0x0A8 | `!entry` |
| SizeOfImage | 0x0D0 | `align(vsize, 0x1000) + 0x1000` |
| фиксация стека | 0x0E8 | `!stackcom` (младшее слово, dword-запись) |
| фиксация кучи | 0x0F8 | `!heapcom` (младшее слово, dword-запись) |
| DD[1] Import | 0x110 | `!idata` (rva, размер) |
| DD[12] IAT | 0x168 | `!iat` (rva, размер) |
| VirtualSize | 0x190 | `vsize` |
| SizeOfRawData | 0x198 | `align(imgsize, 0x200)` |

Итоговый файл = 0x200 байт заголовков + image.bin + нули до
`0x200 + SizeOfRawData`. Размер файла = `0x200 + align(imgsize, 0x200)`.

## Ограничения v1

- image.bin ≤ 0x10000 байт (предел 4-значных смещений ATOM v1);
- ctrl.peg < 0x10000 байт; имя файла ≤ 127 байт;
- имя модуля ≤ 31 байта (заглушка ≤ 0x40 байт сsuffix-ом);
- семантика значений не проверяется (ответственность .peg-файла —
  философия hexgen: строгий синтаксис, доверие данным).

## Коды возврата и сообщения

| Код | Строка | Случай |
|---|---|---|
| 0 | (пусто) | успех |
| 2 | `U-L0-PEGEN CMDS: PEGEN <IMAGE.BIN> <CTRL.PEG> <OUT.EXE>` | меньше трёх аргументов |
| 3 | `U-L0-PEGEN ERR=LONG NAME` | имя длиннее 127 байт |
| 4 | `U-L0-PEGEN ERR=OPEN IMAGE` | image.bin не открыт |
| 5 | `U-L0-PEGEN ERR=READ IMAGE` | ошибка чтения image.bin |
| 6 | `U-L0-PEGEN ERR=BIG IMAGE` | image.bin больше 64 КиБ |
| 7 | `U-L0-PEGEN ERR=OPEN PEG` | ctrl.peg не открыт |
| 8 | `U-L0-PEGEN ERR=READ PEG` | ошибка чтения/размер ctrl.peg |
| 9 | `U-L0-PEGEN ERR=FORMAT` | плохой формат PEG (в т.ч. нет обязательных директив) |
| 10 | `U-L0-PEGEN ERR=OPEN OUT` | out.exe не создан |
| 11 | `U-L0-PEGEN ERR=WRITE OUT` | ошибка записи out.exe |

## Пример (seed.peg модуля M0-SEED)

```
; UNIVERSAL / PEG v1 / слой L0 / модуль M0-SEED
!module seed
!entry 1000
!idata 1100 28
!iat 1130 20
```

Значения `!idata`/`!iat` берутся из раскладки секции модуля (RVA таблиц
импорта в его BYTECODE.md). Директивы `!bss`, `!stackcom`, `!heapcom`
опущены — действуют значения по умолчанию.
