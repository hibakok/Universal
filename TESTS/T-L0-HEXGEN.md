# Тест-план M0-HEXGEN (первый компилятор: ATOM → бинарник)

Паспорт файла: TESTS/T-L0-HEXGEN.md | слой: L0 | роль: тесты модуля M0-HEXGEN.

Короткий префикс тестов модуля — `T-M4`. Все тесты ручные, каждый занимает
секунды. Запуск — из папки `KERNEL\L0-HEXGEN`. Сравнение файлов — `fc /b`,
хэшей — `certutil -hashfile ... SHA256`.

## T-M4-01 — подлинность файла

- Шаги: `certutil -hashfile hexgen.exe SHA256`
- Эталон: `947AD0182A0162CB402CB4D92A7932681CE6B2BF16B5B524ACCE07AB3FD241BF`
- Проверяет: целостность материализации листинга hexgen.hex.
- Время: ~1 с.

## T-M4-02 — DoD этапа E3: сборка семени (главный тест)

- Шаги: `hexgen.exe ..\L0-SEED\seed.hex t_seed.exe`
- Эталон: вывод пуст; код 0; `fc /b t_seed.exe ..\L0-SEED\seed.exe`
  сообщает «Различий не найдено»; SHA-256 = 615D3292CCDD08664F7ACFCF9EF39E55F37443D1BF5A5F3E40D1CC796E64DBDF.
- Проверяет: K0-C021..C025, K0-F011, K0-F004, K0-F013, K0-R001..R006, K0-F005, K0-F006.
- Время: ~1 с.

## T-M4-03 — вызов без аргументов

- Шаги: `hexgen.exe`
- Эталон: `U-L0-HEXGEN CMDS: HEXGEN <IN.HEX> <OUT.BIN>` + CRLF (45 байт); код 2.
- Проверяет: K0-C022 (конец строки), K0-U031.

## T-M4-04 — только один аргумент

- Шаги: `hexgen.exe ..\L0-SEED\seed.hex`
- Эталон: та же справка (45 байт); код 2.
- Проверяет: K0-C025 + проверку второго слова в K0-G031.

## T-M4-05 — сборка семени-2 и hxdump

- Шаги: `hexgen.exe ..\L0-SEED2\seed2.hex t2.exe`; `hexgen.exe ..\L0-HXDUMP\hxdump.hex t3.exe`
- Эталон: коды 0; `fc /b` — различий нет с seed2.exe и hxdump.exe соответственно.
- Проверяет: устойчивость разбора к большим листингам (358 строк, 337 @-строк).

## T-M4-06 — самосборка (круг)

- Шаги: `hexgen.exe hexgen.hex t_hexgen.exe`; `fc /b t_hexgen.exe hexgen.exe`
- Эталон: код 0; различий нет.
- Проверяет: компилятор собирает сам себя (bootstrap-круг E3).

## T-M4-07 — несуществующий вход

- Шаги: `hexgen.exe no_such.hex t.bin`
- Эталон: `U-L0-HEXGEN ERR=OPEN INPUT` + CRLF (28 байт); код 4.
- Проверяет: ветвь −1 после CreateFileA в K0-F011.

## T-M4-08 — плохой формат: посторонний символ

- Шаги: создать `bad.hex` со строкой `X123`; `hexgen.exe bad.hex t.bin`
- Эталон: `U-L0-HEXGEN ERR=FORMAT` + CRLF (24 байта); код 7.
- Проверяет: классификацию строк в K0-R001.

## T-M4-09 — плохой формат: строчные цифры

- Шаги: создать `lower.hex` со строкой `@0000 ab`; `hexgen.exe lower.hex t.bin`
- Эталон: ERR=FORMAT (24 байта); код 7.
- Проверяет: строгость K0-R002 (ATOM v1 — только ЗАГЛАВНЫЕ).

## T-M4-10 — плохой формат: перевёрнутый диапазон

- Шаги: создать `inv.hex` со строкой `Z 0010 0005`; `hexgen.exe inv.hex t.bin`
- Эталон: ERR=FORMAT; код 7.
- Проверяет: проверку «от ≤ до» в K0-R005.

## T-M4-11 — плохой формат: мусор после диапазона

- Шаги: создать `tail.hex` со строкой `Z 0000 0008 XYZ`; `hexgen.exe tail.hex t.bin`
- Эталон: ERR=FORMAT; код 7.
- Проверяет: строгий хвост K0-R005.

## T-M4-12 — выход за пределы образа

- Шаги: создать `over.hex`: `@FFF0 ` + 32×`41 `; `hexgen.exe over.hex t.bin`
- Эталон: ERR=FORMAT; код 7 (запись останавливается на границе 0x10000).
- Проверяет: проверку границ в K0-R004.

## T-M4-13 — имя длиннее 127 байт

- Шаги: `hexgen.exe <имя из 128+ символов>.hex t.bin`
- Эталон: `U-L0-HEXGEN ERR=LONG NAME` + CRLF (27 байт); код 3.
- Проверяет: предел буфера K0-D033/D034, флаг K0-C024.

## T-M4-14 — нет пути для выхода

- Шаги: создать корректный `ok.hex` (`@0000 41`); `hexgen.exe ok.hex nodir\t.bin`
- Эталон: `U-L0-HEXGEN ERR=OPEN OUTPUT` + CRLF (29 байт); код 8.
- Проверяет: ветвь −1 после CreateFileA в K0-F005.

## Дополнительные проверки (одним прогоном)

- Вход ровно 64 КиБ и больше: `ERR=BIG INPUT` (27 байт), код 6.
- CRLF-листинг собирается как LF-листинг (те же байты).
- Комментарии и пустые строки игнорируются.
- Пустой вход даёт пустой выход (код 0).
