# Тест-план M0-SEED (семя)

Паспорт файла: TESTS/T-L0-SEED.md | слой: L0 | роль: тесты модуля M0-SEED.

Все тесты ручные (до этапа E3), каждый занимает секунды.

## T-M0-01 — подлинность файла

- Шаги: `certutil -hashfile seed.exe SHA256`
- Эталон: `615D3292CCDD08664F7ACFCF9EF39E55F37443D1BF5A5F3E40D1CC796E64DBDF`
- Проверяет: целостность материализации листинга.
- Время: ~1 с.

## T-M0-02 — вывод программы

- Шаги: запустить `seed.exe` в консоли.
- Эталон (строго): `U-L0-SEED OK IMAGE=0x00002000` + перевод строки CRLF.
  Итого 31 байт вывода: 21 байт префикса, 8 цифр, 0x0D 0x0A.
- Проверяет: кирпичи K0-P001 (печать), K0-H001 (hex-цифры), K0-D001 (данные).
- Время: ~1 с.

## T-M0-03 — код возврата

- Шаги: `seed.exe` затем `echo %errorlevel%`.
- Эталон: `0`.
- Проверяет: K0-X002 exit_ok.
- Время: ~1 с.

## T-M0-04 — самосогласованность образа

- Шаги: сравнить напечатанное число с полем SizeOfImage в заголовке.
- Эталон: вывод оканчивается на `00002000`; поле по смещению файла 0xD0
  равно `00 20 00 00` (то же число 0x2000 в little-endian). Сверка —
  по таблице раздела «Опциональный заголовок» в `KERNEL/L0-SEED/BYTECODE.md`.
- Проверяет: K0-S001, K0-S002 (чтение собственного заголовка).
- Время: ~1 с (по документации).

## T-M0-05 — контрольные байты (соответствие листингу)

- Шаги: открыть seed.exe в hex-просмотрщике и сверить точки:

| Файл-смещение | Байт | Что это |
|---|---|---|
| 0x000 | `4D` | 'M' сигнатуры MZ |
| 0x03C | `80` | младший байт e_lfanew = 0x80 |
| 0x084 | `64` | младший байт Machine = 0x8664 |
| 0x0B3 | `40` | байт ImageBase 0x140000000 |
| 0x0D0 | `00` | младший байт SizeOfImage = 0x2000 |
| 0x110 | `00` | младший байт RVA таблицы импорта 0x1100 |
| 0x200 | `48` | первый байт кода (REX.W) |
| 0x27E | `CC` | страховочный int3 |
| 0x280 | `55` | 'U' — первый байт строки вывода |
| 0x29F | `30` | '0' — первый байт таблицы цифр |
| 0x300 | `60` | младший байт INT RVA 0x1160 |
| 0x380 | `6B` | 'k' — первый байт "kernel32.dll" |
| 0x3FF | `00` | последний байт файла (нулевая заливка) |

- Эталон: все 13 точек совпадают.
- Проверяет: соответствие exe листингу seed.hex (выборочная сверка).
- Время: ~2 мин вручную.

## Журнал прогонов

| Дата | Тесты | Результат |
|---|---|---|
| Этап E0 | T-M0-01..T-M0-05 | методики определены; T-M0-01..04 подтверждены тремя уровнями верификации (PE-разбор, дизассемблер, эмуляция); T-M0-05 — контрольные байты сверены автоматически при сборке |
