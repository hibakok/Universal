# Тест-план M0-PEGEN (обёртка образов)

Паспорт файла: TESTS/T-L0-PEGEN.md | слой: L0 | роль: тесты модуля M0-PEGEN.

Короткий префикс тестов модуля — `T-M5`. Все тесты ручные, каждый занимает
секунды. Запуск — из папки `KERNEL\L0-PEGEN` (круги — из папки `KERNEL`).
Сравнение файлов — `fc /b`, хэшей — `certutil -hashfile ... SHA256`.

## T-M5-01 — подлинность файла

- Шаги: `certutil -hashfile pegen.exe SHA256`
- Эталон: см. `KERNEL/L0-PEGEN/VERIFY.md` (паспорт артефакта).
- Проверяет: целостность конвейера hexgen+pegen над pegen.hex/pegen.peg.
- Время: ~1 с.

## T-M5-02 — DoD этапа E4: полный круг семени (главный тест)

- Шаги (из папки KERNEL):
  `L0-HEXGEN\hexgen.exe L0-SEED\seed.hex t_body.bin`
  `L0-PEGEN\pegen.exe t_body.bin L0-SEED\seed.peg t_seed.exe`
  `fc /b t_seed.exe L0-SEED\seed.exe`
- Эталон: оба кода 0; вывод пуст; различий нет; SHA-256 t_seed.exe =
  615D3292CCDD08664F7ACFCF9EF39E55F37443D1BF5A5F3E40D1CC796E64DBDF.
- Проверяет: K0-C031..C036, K0-F021..F025, K0-Q001..Q011, K0-M001,
  K0-E001..E004, K0-G041, K0-G042 — весь конвейер «текст → EXE».
- Время: ~2 с.

## T-M5-03 — круг семени-2

- Шаги: как T-M5-02, но seed2.hex + seed2.peg; fc /b с seed2.exe.
- Эталон: различий нет (SHA-256 190DE94E…EE87).
- Проверяет: устойчивость к 0x482-байтному телу, перенос VirtualSize≠SRD.

## T-M5-04 — круг hxdump (фиксации 16 КиБ)

- Шаги: как T-M5-02, но hxdump.hex + hxdump.peg; fc /b с hxdump.exe.
- Эталон: различий нет (F0CEE97E…4A8E3).
- Проверяет: директивы !stackcom/!heapcom 4000.

## T-M5-05 — круг hexgen (виртуальные нули)

- Шаги: как T-M5-02, но hexgen.hex + hexgen.peg; fc /b с hexgen.exe.
- Эталон: различий нет (947AD018…241BF).
- Проверяет: директиву !bss 20080; самохостинг hexgen сохранён.

## T-M5-06 — самосборка pegen (круг)

- Шаги (из папки KERNEL):
  `L0-HEXGEN\hexgen.exe L0-PEGEN\pegen.hex t_pb.bin`
  `L0-PEGEN\pegen.exe t_pb.bin L0-PEGEN\pegen.peg t_pegen.exe`
  `fc /b t_pegen.exe L0-PEGEN\pegen.exe`
- Эталон: коды 0; различий нет.
- Проверяет: обёртка собирает сам себя (bootstrap-круг E4).

## T-M5-07 — вызов без аргументов

- Шаги: `pegen.exe`
- Эталон: `U-L0-PEGEN CMDS: PEGEN <IMAGE.BIN> <CTRL.PEG> <OUT.EXE>` + CRLF
  (57 байт); код 2.
- Проверяет: K0-C032 (конец строки), K0-G042 (элемент 0 таблицы).

## T-M5-08 — один и два аргумента

- Шаги: `pegen.exe a.bin`; `pegen.exe a.bin b.peg`
- Эталон: та же справка (57 байт); код 2 в обоих случаях.
- Проверяет: K0-C036 (пропущенные аргументы).

## T-M5-09 — несуществующий образ

- Шаги: `pegen.exe no.bin t.peg out.exe` (no.bin не существует)
- Эталон: `U-L0-PEGEN ERR=OPEN IMAGE` + CRLF (28 байт); код 4.
- Проверяет: ветвь −1 после CreateFileA в K0-F021.

## T-M5-10 — несуществующий peg

- Шаги: `pegen.exe a.bin no.peg out.exe` (a.bin — любой существующий)
- Эталон: `U-L0-PEGEN ERR=OPEN PEG` + CRLF (26 байт); код 7.

## T-M5-11 — имя длиннее 127 байт

- Шаги: `pegen.exe <имя из 128+ символов>.bin b.peg out.exe`
- Эталон: `U-L0-PEGEN ERR=LONG NAME` + CRLF (27 байт); код 3.
- Проверяет: предел буферов K0-D046, флаг K0-C034 через K0-C036.

## T-M5-12 — директивы с комментариями и пустыми строками

- Шаги: создать `c.peg` с комментариями `;`, пустыми строками, CRLF и
  всеми 7 директивами; собрать любой образ.
- Эталон: код 0; результат как у того же peg без комментариев.
- Проверяет: K0-Q001 (строки/комментарии), K0-Q010 (имя), CRLF.

## T-M5-13 — плохой формат: неизвестное слово / строчные цифры / мусор

- Шаги: три peg-файла: `!modul x…`; `!entry 100a` (строчная 'a');
  `!entry 1000 xyz`; `pegen.exe a.bin <файл> out.exe`
- Эталон: `U-L0-PEGEN ERR=FORMAT` + CRLF (24 байта); код 9.
- Проверяет: K0-Q002 (границы слова), K0-Q007 (ЗАГЛАВНЫЕ), K0-Q004 (хвост).

## T-M5-14 — нет обязательной директивы

- Шаги: peg без !module (остальные есть); peg без !iat.
- Эталон: ERR=FORMAT; код 9.
- Проверяет: маску 0xF в K0-Q001.

## T-M5-15 — выход не создан

- Шаги: `pegen.exe a.bin b.peg nodir\out.exe` (каталог nodir не существует)
- Эталон: `U-L0-PEGEN ERR=OPEN OUT` + CRLF (26 байт); код 10.
- Проверяет: ветвь −1 после CreateFileA в K0-F022.

## T-M5-16 — значения разной длины; повтор директивы

- Шаги: peg с `!entry 1000` и `!bss 0` (1..4 цифры) и отдельный peg с
  `!entry 1000` … затем ещё раз `!entry 1008`.
- Эталон: коды 0; во втором случае действует последнее значение
  (точка входа 1008 — проверить дампом t.exe: байты 0xA8..0xAB = 08 10 00 00).
- Проверяет: K0-Q003 (1..8 цифр), «последняя директива побеждает».

## T-M5-17 — образ ровно 64 КиБ и больше

- Шаги: `a.bin` из 0x10000 байт (собрать hexgen-ом из листинга с
  покрытием до 0xFFFF…0x10000); затем 0x10001 байт.
- Эталон: первый — код 0 (файл 0x10200); второй — `U-L0-PEGEN ERR=BIG IMAGE`
  + CRLF (26 байт), код 6.
- Проверяет: границу вместимости imagebuf в K0-G041.
