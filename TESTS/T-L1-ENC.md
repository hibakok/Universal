Паспорт файла: TESTS/T-L1-ENC.md | слой: L1 | роль: тест-план кодировщика ENC.

## Оракул (сейчас, автоматические)

### T-E6-01  Якорные кодировки
Шаги: для каждой пары (M-строка, H-строка) из `lab_enc_cases.CASES`
(102 случая: реальный код brick.brick + реестр SPEC/05 + канонические
формы) выполнить `lab_enc.normalize` и сравнить с эталоном.
Эталон: байт-в-байт; источники — H-строки `KERNEL/L1-BRICK/brick.brick`
и таблицы SPEC/05.
Время: < 0,1 с.

### T-E6-02  Отвержение некорректных M-строк
Шаги: для каждой строки из `lab_enc_cases.ERRORS` (21 случай) убедиться,
что `normalize` возбуждает `EncError` ("FORMAT AT=...").
Эталон: все 21 отвергаются; ни одна не проходит.
Время: < 0,1 с.

### T-E6-03  Структурный контроль декодером
Шаги: каждую кодировку из T-E6-01 (слоты заполнены нулями) декодировать
`lab_x86.decode`; длина декодированной инструкции обязана равняться
длине кодировки.
Эталон: 102/102 совпадений длины.
Время: < 0,1 с.

### T-E6-04  Полный круг v2 -> EXE -> эмуляция
Шаги: `DEMO_B2` -> `lab_enc` -> `lab_brick` -> `lab_pegen` -> запуск в
эмуляторе (`lab_run`).
Эталон: stdout `U-ENC-OK\r\n`, код возврата 0.
Время: < 0,5 с.

## Инструмент enc.exe (E6.2, план)

### T-E6-05  Справка без аргументов
Шаги: `enc.exe` без аргументов.
Эталон: `U-L1-ENC CMDS: ENC <SRC.B2> <OUT.BRICK>`, код 2.

### T-E6-06  Равенство оракулу (главный)
Шаги: `enc.exe` на синтезированном файле из всех CASES (по одной
M-строке на строку); выход сравнить с выходом оракула.
Эталон: байт-в-байт (102/102).

### T-E6-07  Отвержение ошибок инструментом
Шаги: для каждой строки ERRORS — прогон enc.exe (в эмуляторе).
Эталон: `U-L1-ENC ERR=FORMAT AT=<строка>`, код 6; номера строк как
у оракула.

### T-E6-08  Круг конвейера на реальном модуле
Шаги: `enc.exe` + `brick.exe` + `pegen.exe` на исходнике, полностью
написанном M-строками; результат запустить в эмуляторе.
Эталон: задокументированный вывод программы.

### T-E6-09  Самохостинг enc
Шаги: enc.exe собирает собственный исходник `.b2`; результат проходит
конвейер и воспроизводит enc.exe байт-в-байт.
Эталон: fc /b без различий (DoD E6.2).

### T-E6-10  Большие исходники
Шаги: исходник на пределе 128 КиБ (генерируется программно).
Эталон: успешная сборка; время < нескольких секунд (эмуляция).

### T-E6-11  Номер строки в ошибке
Шаги: файл с корректными M-строками и одной ошибочной на строке N.
Эталон: `ERR=FORMAT AT=<N в hex>`; номер совпадает с оракулом.
