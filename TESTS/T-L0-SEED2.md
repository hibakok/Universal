# Тест-план M0-SEED2 (семя-2)

Паспорт файла: TESTS/T-L0-SEED2.md | слой: L0 | роль: тесты модуля M0-SEED2.

Короткий префикс тестов модуля — `T-M2`. Все тесты ручные (до этапа
E3), каждый занимает секунды. Запуск — из папки `KERNEL\L0-SEED2`.

## T-M2-01 — подлинность файла

- Шаги: `certutil -hashfile seed2.exe SHA256`
- Эталон: `190DE94E3F3227D421B6779B34985FD1762E127EC50EF864C4ED84814B05EE87`
- Проверяет: целостность материализации листинга seed2.hex.
- Время: ~1 с.

## T-M2-02 — команда entry

- Шаги: `seed2.exe entry`
- Эталон (строго): `U-L0-SEED2 ENTRY=0x00001000` + CRLF (29 байт).
- Проверяет: K0-C001..C004, K0-G001, K0-S012, K0-P012, K0-H011, K0-P011.
- Время: ~1 с.

## T-M2-03 — команда image

- Шаги: `seed2.exe image`
- Эталон: `U-L0-SEED2 IMAGE=0x00002000` + CRLF.
- Проверяет: то же, поле PE+0x50.

## T-M2-04 — команда align

- Шаги: `seed2.exe align`
- Эталон: `U-L0-SEED2 ALIGN=0x00001000` + CRLF.
- Проверяет: то же, поле PE+0x38.

## T-M2-05 — команда sect (16-битное поле)

- Шаги: `seed2.exe sect`
- Эталон: `U-L0-SEED2 SECT=0x00000001` + CRLF (28 байт).
- Проверяет: действие 3 (movzx слова), поле PE+0x06.

## T-M2-06 — эхо аргументов с хвостом

- Шаги: `seed2.exe args hello world`
- Эталон: `U-L0-SEED2 ARGS: hello world` + CRLF (30 байт).
- Проверяет: K0-A001, K0-C005, неволатильность r13/r14.
- История: тест поймал дефект хранения длины в rcx (см. VERIFY.md).

## T-M2-07 — эхо без хвоста

- Шаги: `seed2.exe args`
- Эталон: `U-L0-SEED2 ARGS:` + CRLF (18 байт; без хвостового пробела).
- Проверяет: пустая ветвь K0-A001.

## T-M2-08 — вызов без команды

- Шаги: `seed2.exe`
- Эталон: `U-L0-SEED2 CMDS: ENTRY IMAGE ALIGN SECT ARGS` + CRLF
  (46 байт); код возврата 0.
- Проверяет: K0-C002 (конец строки), K0-U001.

## T-M2-09 — неизвестная команда

- Шаги: `seed2.exe bogus`
- Эталон: справка (как T-M2-08); код возврата 2.
- Проверяет: ветвь «не найдено» K0-C004.

## T-M2-10 — коды возврата

- Шаги: `seed2.exe entry` → `echo %errorlevel%`; `seed2.exe bogus`
  → `echo %errorlevel%`.
- Эталон: 0, затем 2.
- Проверяет: K0-X012.

## T-M2-11 — самосогласованность образа

- Шаги: сравнить вывод entry/image/align/sect с полями заголовка
  (смещения 0xA8, 0xD0, 0xB8, 0x86; таблица — BYTECODE.md, раздел 1).
- Эталон: все четыре числа совпадают с файлом байт-в-байт.
- Проверяет: K0-S011, K0-S012 (динамическое чтение через e_lfanew).

## T-M2-12 — контрольные байты (соответствие листингу)

- Шаги: открыть seed2.exe в hex-просмотрщике и сверить точки:

| Смещение | Байт | Что это |
|---|---|---|
| 0x000 | `4D` | 'M' сигнатуры MZ |
| 0x03C | `80` | младший байт e_lfanew = 0x80 |
| 0x0A8 | `00` | младший байт точки входа RVA 0x1000 |
| 0x0D0 | `00` | младший байт SizeOfImage = 0x2000 |
| 0x198 | `00` | SizeOfRawData = 0x600 (байт 0x19A = `06`) |
| 0x200 | `48` | первый байт кода (REX.W, K0-X011) |
| 0x21F | `FF` | начало call GetCommandLineA |
| 0x269 | `E8` | call print_usage (ветвь noargs) |
| 0x270 | `E9` | jmp exit_proc (окончание ветви noargs) |
| 0x470 | `55` | 'U' первая строка вывода (RVA 0x1270) |
| 0x560 | `65` | 'e' имя "entry" в таблице команд (RVA 0x1360) |
| 0x5B0 | `10` | младший байт OFT = INT RVA 0x1410 (IDT) |
| 0x638 | `6B` | 'k' "kernel32.dll" (RVA 0x1438) |
| 0x672 | `47` | 'G' имя GetCommandLineA (RVA 0x1470 + hint 2) |
| 0x7FF | `00` | последний байт файла (нулевая заливка) |

- Эталон: все 15 точек совпадают.
- Время: ~2 мин вручную.
