# T-PROJECTS. Тест-план проектов PROJECTS/ (слой L6)

Паспорт файла: TESTS/T-PROJECTS.md | слой: L6 | роль: тест-план проектов
PROJECTS/ (реестр тестов проектов; формат — TESTS/POLICY.md).

Обязательство проекта (PROJECTS/README п. 5, SPEC/14): каждая программа
обязана собираться конвейером splice.exe -> uva.exe -> kernel.exe
(склейка !include -> ассемблирование -> исполнение) и давать вывод,
байт-в-байт равный якорю этого файла И оракулу `LAB/py/lab_l4.py`
(композиция по контракту программы). Правка программы без обновления
якоря = незавершённое изменение (красный тест батареи).

Автоматизация: батарея, секция 17 (`LAB/py/lab_t_prj.py`, группа 3:
`python3 LAB/ai/battery_groups.py 3`; реестры — MAP/INDEX.md).
Свидетели: инструменты (круг) == оракул lab_l4 == якорный литерал.
Тест читает РЕАЛЬНЫЕ исходники из PROJECTS/ — файл есть, копий нет.

## T-P-01. banner: круг инструментами (все 4 ветви C+N+S+M)

Шаги: `splice.exe PROJECTS/banner/banner.uva banner.flat.uva` ->
`uva.exe banner.flat.uva banner.up` -> `kernel.exe banner.up`
(эмуляция LAB); сверка: коды 0/0/0, байты banner.up ==
`lab_vm.assemble(flat)`, консоль == оракулу == якорю.
Эталон (якорь, полный вывод):
`UNIVERSAL\r\n========================\r\nOPS 24 RAM 4096\r\n`
`I64 -9223372036854775808\r\nLEN 9\r\n`
(24 '='; край −2^63 из .data через ldq; разделитель — mem_fill
RAM[100..124) + buf_out; контейнер .UP v2, данные 39 Б).
Время: секунды (эмуляция трёх инструментов).

## T-P-02. fib: круг инструментами (C+N, зависимость N->C)

Шаги: `splice.exe PROJECTS/fib/fib.uva fib.flat.uva` -> `uva.exe
fib.flat.uva fib.up` -> `kernel.exe fib.up` (эмуляция LAB); сверка:
коды 0/0/0, байты fib.up == `lab_vm.assemble(flat)`, консоль ==
оракулу (ряд Фибоначчи, счёт на Python) == якорю.
Эталон (якорь, полный вывод):
`1: 1\r\n2: 1\r\n3: 2\r\n4: 3\r\n5: 5\r\n6: 8\r\n7: 13\r\n`
`8: 21\r\n9: 34\r\n10: 55\r\n11: 89\r\n12: 144\r\n13: 233\r\n`
(13 членов; контейнер .UP v1 — .data нет; обе части lib_c + lib_n
обязаны быть включены — зависимость N->C; состояние цикла —
в сохраняемых r5..r10 через вызовы кирпичей, ABI SPEC/14 п. 3).
Время: секунды.
