## Инструмент splice.exe (автоматические, секция 8 батареи)

### T-E6-12  Справка
Шаги: запуск без аргументов (эмуляция).
Эталон: `U-L1-SPLICE CMDS: SPLICE <ROOT.SRC> <OUT.FLAT>\r\n`, код 2.
Время: < 0,5 с.

### T-E6-14  Инструмент == якорям
Шаги: все CASES через splice.exe (эмуляция).
Эталон: код 0, пустой stdout, файл = якорь.
Время: < 1 с.

### T-E6-15  Отвержение
Шаги: все ERRORS через splice.exe (эмуляция); с E6.4e-2 якоря BIG SRC
(включение 0x40000) и BIG OUT (выход 0x400FF) — на новых границах 256 КиБ.
Эталон: код возврата и строка `U-L1-SPLICE ERR=<msg>\r\n` — в точности
как у оракула (включая AT= сквозной нумерации).
Время: ~4 с (BIG OUT — сканирование 256 КиБ).

### T-E6-16  Большой исходник
Шаги: корень + часть 23 КиБ (1480 строк).
Эталон: байт-в-байт с якорем.
Время: < 2 с.

### T-E6-16b  Пределы 256 КиБ (E6.4e-2)
Шаги: (1) корень 0x20020 байт одной строкой; (2) корень с включением
0x20020 байт (проверяет адресацию уровня shl 18 и буфер уровня 1);
(3) включение 0x40000 байт.
Эталон: (1,2) код 0, выход == вход (старые FILECAP/OUTCAP 0x20000
отвергли бы оба); (3) код 7, `U-L1-SPLICE ERR=BIG SRC\r\n`.
Время: ~5 с.

### T-E6-17  Разрезы репозитория
Шаги: splice.exe на корнях `l1-enc/enc.b2`, `l1-brick/brick.brick`,
`l1-splice/splice.b2`, `l2-wall/wall.b2` (с E6.4e-2; реальные файлы
KERNEL, wall — крупнейший: выход 130217 Б); сравнение с оракулом.
Эталон: байт-в-байт (префиксы каталогов разрешены инструментом).
Время: ~6 с.

### T-E6-18  Самохостинг разреза
Шаги: `splice.exe(l1-splice/splice.b2)` -> плоско; `enc.exe` ->
splice.brick; `brick.exe` -> тело; `pegen.exe` -> EXE (все — реальные
инструменты под эмуляцией).
Эталон: каждый шаг код 0; splice.brick и splice.exe байт-в-байт равны
артефактам репозитория.
Время: ~5 с.

## Интеграционные следствия разреза (в других секциях батареи)

- T-M6-16 / круги E5: `brick(splice(brick.brick)) == hexgen(brick.hex)`
  (секция 5) — тело brick не изменилось от разреза.
- T-E6-09: `enc(splice(enc.b2)) == enc.brick` и круг -> enc.exe
  (секция 7) — самохостинг enc не изменился от разреза.
- SHA-256 + PE-инварианты splice.exe — секции 1–2 (как у всех образов).

## Ручные приёмочные (Windows, из папки KERNEL)

```
L1-SPLICE\splice.exe L1-ENC\enc.b2 t_flat.b2
L1-ENC\enc.exe t_flat.b2 t_v1.brick
fc /b t_v1.brick L1-ENC\enc.brick      ->  различий нет (разрез верен)

L1-SPLICE\splice.exe L1-BRICK\brick.brick t_flat.brick
L1-BRICK\brick.exe t_flat.brick t_self.bin
L0-HEXGEN\hexgen.exe L1-BRICK\brick.hex t_body.bin
fc /b t_self.bin t_body.bin            ->  различий нет (DoD E6.3)
```
