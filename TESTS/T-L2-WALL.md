## Автоматические (батарея, ~1 с)

### T-E6-19 якоря компиляции (10)
Шаги: для каждой пары (исходник, ожидание) из `LAB/py/lab_l2_cases.py`
(CASES_FULL — полный выход байт-в-байт; CASES_FRAG — обязательный
непрерывный фрагмент) вызвать `lab_l2.compile_wall`.
Эталон: 4 полных якоря (минимум; локали/темпы/str/len; if-else/while
с метками; ext-область и 5-й аргумент) + 6 фрагментов (параметры/return/
стейдинг C; getb/setb и S-слоты; сдвиги через cl и вложенность T;
данные-строки и экраны; return без значения и порядок функций; if без
else). Якоря выписаны вручную — независимо от оракула.
Время: < 0,1 с. Эталон количества: 10.

### T-E6-20 отвержение некорректных программ (26)
Шаги: compile_wall каждого исходника из ERRORS (`LAB/py/lab_l2_prog.py`).
Эталон: WallError с точным номером строки (26 случаев: имена, main,
блоки, приоритеты, диапазоны, объявления после func, ext-аргументы,
экраны, вызовы не-функций, & на функции, setb в выражении…).
Время: < 0,1 с.

### T-E6-21 полный круг WALL -> EXE -> эмуляция
Шаги: DEMO_WALL -> compile_wall -> lab_enc -> lab_brick -> lab_pegen
(DEMO_WALL_PEG) -> lab_run.
Эталон: stdout `U-WALL-OK 37\r\n`, код 0. Сумма 1..10 = 55 = 0x37
печатается двумя hex-цифрами через setb — нетривиальная программа
на языке (функции, циклы, условия, строки, импорты kernel32).
Время: < 1 с. Примечание: ~402 шага эмуляции.

### T-E6-22 PE-инварианты демо-EXE по SPEC/11
Шаги: lab_pe.parse демо-EXE; check_spec04 + явные значения SPEC/11.
Эталон: единственное допустимое отклонение от SPEC/04 — «точка входа
!= 0x1000»; при этом entry=0x1200, DD[1]=1000/28, DD[12]=1028/48;
hint-записи на чётных RVA (инвариант 7 SPEC/04 соблюдён по построению).
Время: < 0,1 с.

### T-E6-23 большой исходник
Шаги: big_source() (1203 строки, детерминированный генератор:
12 функций с циклами + hexnib + setb/getb) -> компиляция дважды ->
enc -> brick.
Эталон: выходы идентичны (детерминизм); тело собирается (~64 КиБ).
Время: ~1 с.

### T-E6-24 все выходы кодируются
Шаги: каждый исходник якорей + демо -> compile_wall -> enc.normalize
-> lab_brick.assemble.
Эталон: ни одна M-строка выхода не отвергается enc; тела собираются.
Время: < 1 с.

## Журнал находок (якоря против оракула, E6.4a)

1. Вызов в позиции ВЫРАЖЕНИЯ не учитывался при расчёте C-слотов —
   кадр выходил меньше необходимого (слоты C попадали в зону тени).
   Поймано якорем F4 (sub rsp, 50 вместо 40 у main с r = add2(3, 4)).
   Исправлено: обход выражений Layout._scan_expr.
2. Дублирующийся эпилог: завершающий «выход» emit'ился и после тела,
   оканчивающегося return. Поймано якорем F4/F9. Правило SPEC/11 п. 8:
   завершающего эпилога нет, если последнее утверждение — return.
3. Счётчик функций в заголовке выхода: +1 лишний (main входит в
   funcs). Поймано якорями A1/A2/A3/A5.
4. Номер строки программных ошибок: фантомная хвостовая строка →
   заменено на последнюю непустую (SPEC/11 п. 10). Поймано ERR-якорем.
