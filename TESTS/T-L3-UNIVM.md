### T-E7-01  Якорные кодировки
Шаги: 18 строк ассемблера (по одной на каждый опкод) собираются
мини-ассемблером; байты сверяются с якорями, выписанными вручную

### T-E7-15  ALU среза 2 — диффтест
Шаги: 17 случаев против оракула (консоль/код возврата/TRAP+STEPS):
(1) поля-заполнители — const ra!=0, mov rb!=0, add rb=16, xor

Эталон: ядро == оракулу на каждом случае (R8). Результаты ALU

### T-E7-16  Память и устройства среза 3 — диффтест
Шаги: 15 случаев против оракула (консоль/код возврата/TRAP+STEPS;
консоль = окно+0 делает значения регистров/RAM наблюдаемыми —
результаты eq-проверок печатаются байтами «'0'/'1'»):
(1) консоль-строка «MEM-OK\r\n» через stb в окно+0, halt 37;
(2) RAM: sext8 (байт 0x80 → −128) и нулевой старт (RAM[6] = 0 ==
r0); (3) слова: stq/ldq по невыровненному адресу 3 — LE-байты
(0xFF на +0, 0x80 на +7) и слово целиком == источнику
(0x80000000000000FF); (4) заворот адреса: base = −16, смещение +16 →
адрес 0 (RAM[0]); (5) окно: запись в резерв (окно+1) игнорируется
без ловушки, чтение окна (окно+0 и окно+1) = 0; (6) memsize = 0:
консоль по адресу 0, ldq — ловушка 3; (7) ловушки 3/4 — 9 программ:
ldq/stq за верхом (12+8>16), ldq/stq в окне (слова запрещены),
ldb/stb ровно за окном (memsize+4096), stb с битом 31 (2^31−1 и
4×10^9 — фильтр «a >> 31»), ldb с заворотом (−1 → 2^64−1).
Эталон: ядро == оракулу на каждом случае (R8); шаги до ловушки —
точные (незавершённая инструкция шагом не считается). Время: < 5 с.

### T-E7-17  Переходы среза 4 — диффтест (ВЫПОЛНЕН)
Шаги: 9 случаев против оракула (консоль/код возврата/TRAP+STEPS):
(1) полный корпус программ T-E7-04..08 — демо «U-VM-OK 37» (петли
jnz вперёд/назад, 142 шага), ops-программа (jmp через мёртвый код,
код 7), dev (печать «AA» через окно); (2) jnz ВПЕРЁД через ловушку
(взят — пропущен ldb вне памяти); (3) jnz НЕ ВЗЯТ (r1 = 0 — pc+6 в
halt; цель не проверяется); (4) конечная петля назад (3 итерации);
(5) jmp на границу кода (pc == codesize → trap 2, шаг 1);
(6) цели за кодом: jmp 999999 → trap 2 (шаг 1), jnz на плохую цель
→ trap 2 (шаг 2 — переход исполнен, провалена следующая выборка).
Эталон: ядро == оракулу (R8). Время: < 2 с.

### T-E7-18  Предел шагов — trap 6 (ВЫПОЛНЕН)

сборки; печать QZZQ — байты у границы кусков); (6) v1-контейнер —
регрессия; (7) v2 dataoff=0 — v1-эквивалент (тот же код — тот же
