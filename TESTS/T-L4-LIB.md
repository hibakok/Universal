# T-L4-LIB. Тест-план библиотеки L4 (M4-LIB)

Паспорт файла: TESTS/T-L4-LIB.md | слой: L4 | роль: тест-план модуля M4-LIB.

Обязательство модуля (SPEC/14 п. 4/6): реализация каждого кирпича
(части `KERNEL/L4-LIB/lib_*.uva`, срезы E8.2+) обязана совпадать с
оракулом `LAB/py/lab_l4.py` по наблюдаемому поведению — консоль,
RAM, регистры — на корпусе якорей `LAB/py/lab_l4_cases.py`
(и на программах диффтеста срезов). Срез 1 (E8.1 — «сначала истина
семантики», прецедент E7.1): САМ ОРАКУЛ сверен с якорями —
ручными литералами SPEC/14 п. 4; реализаций .uva ещё нет
(карточки-план — MAP/M4-LIB.md, R3).

Автоматизация: все тесты — батарея (секция 16, `LAB/py/lab_t_l4.py`;
группа 3: `python3 LAB/ai/battery_groups.py 3`). Время: мгновенно
(чистый Python, без эмуляции); реализации E8.2+ добавят диффтесты
(путь .uva → uva.exe → kernel.exe, как секции 14/15).

## T-E8-01. print_u64 == якорям DEC

Шаги: для каждого якоря DEC (13 значений: 0; 1; 9; 10; 99; 100;
1000; 123456789; 2^32−1; 2^32; 2^63−1; 2^63; 2^64−1) —
`lab_l4.print_u64(v)`.
Эталон: bytes якоря («18446744073709551615» для максимума и т.д.);
край 0 → «0» (одна цифра, не пусто).
Время: мгновенно.

## T-E8-02. print_i64 == якорям I64

Шаги: для каждого якоря I64 (6 значений дополнения до двух: 0; 1;
+2^63−1; 2^63 — край −2^63; −10; −1) — `lab_l4.print_i64(v)`.
Эталон: знаковая запись якоря; «-9223372036854775808» (19 цифр) —
край без переполнения; знак только «-» (плюс не печатается).
Время: мгновенно.

## T-E8-03. u64_to_dec_rev == якорям REV

Шаги: для каждого якоря REV (6 значений) —
`lab_l4.u64_to_dec_rev(v)`.
Эталон: (реверс-цифры, длина): buf[0] — цифра ЕДИНИЦ («54321» для
12345); 0 → («0», 1); максимум → 20 цифр («51615590737044764481»).
Время: мгновенно.

## T-E8-04. str_len/str_out == якорям STR

Шаги: для каждого якоря STR (5 строк с NUL) — `lab_l4.str_len`
и `lab_l4.str_out`.
Эталон: строка ДО ПЕРВОГО нуля (хвост после NUL невидим: «AB» из
«AB\0CD\0»); пустая строка для ведущего NUL; без NUL — вся строка;
длина не включает NUL.
Время: мгновенно.

## T-E8-05. mem_copy == якорям CPY

Шаги: для каждого якоря CPY (6 случаев; малая RAM) —
`lab_l4.mem_copy(bytearray(исходная), dst, src, n)`.
Эталон: формула SPEC/14 п. 4 (i = 0..n-1, RAM[dst+i] := RAM[src+i]):
без перекрытия; перекрытие ВПЕРЁД — источник затирается до прочтения
(«ABCDEF», dst=1, src=0, n=3 → «AAAAEF»); НАЗАД — без затирания;
dst = src — без изменений; n = 0 — нет эффекта.
Время: мгновенно.

## T-E8-06. mem_fill == якорям FILL

Шаги: для каждого якоря FILL (4 случая) —
`lab_l4.mem_fill(bytearray(исходная), dst, byte, n)`.
Эталон: RAM[dst..dst+n) := byte AND 255 (0x141 → 0x41); n = 0 —
нет эффекта.
Время: мгновенно.

## T-E8-07. Консоль-кирпичи и композиция

Шаги: `chr_out(0x141)`/`chr_out(0)`; `crlf_out()`; для каждого якоря
BUF — `buf_out`/`buf_out_rev`; для CMP_U64/CMP_I64 — конкатенация
`print_u64(v) + crlf_out()` / `print_i64(v) + crlf_out()`.
Эталон: chr_out — байт r1 AND 255 (0x141 → «A»); CRLF = 0D 0A;
прямой/обратный порядок буферов (палиндром «010» — одинаков);
композиция «число + CRLF» — консоль-протокол составных кирпичей
(«18446744073709551615\r\n»; «-9223372036854775808\r\n»).
Время: мгновенно.
