# Тест-план M1-BRICK (ассемблер BRICK v1)

Паспорт файла: TESTS/T-L1-BRICK.md | слой: L1 | роль: тесты модуля M1-BRICK.

Короткий префикс тестов модуля — `T-M6`. Все тесты ручные, каждый занимает
секунды. Запуск — из папки `KERNEL\L1-BRICK` (круги — из папки `KERNEL`).
Сравнение файлов — `fc /b`, хэшей — `certutil -hashfile ... SHA256`.

## T-M6-01 — подлинность файла

- Шаги: `certutil -hashfile brick.exe SHA256`
- Эталон: см. `KERNEL/L1-BRICK/VERIFY.md` (паспорт артефакта).
- Проверяет: целостность конвейера hexgen+pegen над brick.hex/brick.peg.
- Время: ~1 с.

## T-M6-02 — DoD этапа E5: самохостинг (главный тест)

- Шаги (из папки KERNEL):
  `L1-BRICK\brick.exe L1-BRICK\brick.brick t_self.bin`
  `L0-HEXGEN\hexgen.exe L1-BRICK\brick.hex t_body.bin`
  `fc /b t_self.bin t_body.bin`
- Эталон: оба кода 0; вывод пуст; различий нет (2964 байта).
- Проверяет: ассемблер собирает собственный источник BRICK байт-в-байт
  с ATOM-формой того же тела — K1-A001..A010, K1-T001..T004, K1-N001..N002,
  K1-G001 полностью.
- Время: ~2 с.

## T-M6-03 — круг самосборки (полный)

- Шаги (из папки KERNEL):
  `L0-PEGEN\pegen.exe t_self.bin L1-BRICK\brick.peg t_brick.exe`
  `fc /b t_brick.exe L1-BRICK\brick.exe`
- Эталон: код 0; различий нет.
- Проверяет: система воспроизводит brick.exe из BRICK-текста через
  pegen (зависимость L1 → L0 корректна и замкнута).
- Время: ~2 с.

## T-M6-04 — вызов без аргументов

- Шаги: `brick.exe`
- Эталон: `U-L1-BRICK CMDS: BRICK <SRC.BRICK> <OUT.BIN>` + CRLF (46 байт);
  код 2.
- Проверяет: K1-C002 (конец строки), K1-G002 (errtab[0]).

## T-M6-05 — один аргумент

- Шаги: `brick.exe a.brick`
- Эталон: та же справка; код 2.
- Проверяет: K1-C003 (пропущенные аргументы).

## T-M6-06 — минимальный исходник: байты

- Шаги: `t.brick` = `H 48 90\n`; `brick.exe t.brick t.bin`
- Эталон: код 0; t.bin = 2 байта (48 90).
- Проверяет: K1-A002 (parse_h), K1-A007.

## T-M6-07 — метки и 4-байтовый слот (rip)

- Шаги: `t.brick`:
  `:entry\nH 48 83 EC 38\nH 48 8D 1D $base\n`; сборка.
- Эталон: код 0; t.bin = 11 байт; последние 4 = F5 EF FF FF
  (disp32 к RVA 0, как в seed).
- Проверяет: K1-N001 (base — предопределённая), K1-A002 пассаж 2.

## T-M6-08 — rel8-слот

- Шаги: `t.brick`: `:a\nH 74 $b:1\nH 90\n:b\nH CC\n`
- Эталон: код 0; t.bin = 74 01 90 CC (переход на +1).
- Проверяет: суффикс `:1`, диапазон rel8, два пассажа с форвардом.

## T-M6-09 — DD/DQ со ссылками

- Шаги: `t.brick`: `:x\nDB 41\n:y\nDQ $x\nDD $y 20\n`
- Эталон: код 0; t.bin = 41 + 00 10 00 00 00 00 00 00 + 01 10 00 00 +
  20 00 00 00 (RVA меток LE).
- Проверяет: K1-A005 (RVA = L + 0x1000), K1-A006.

## T-M6-10 — DZ и DBZ

- Шаги: `t.brick`: `DZ 3\n:far\nDBZ 10\nH 90\n`
- Эталон: код 0; t.bin = 3 нуля + 90 (2 байта — DBZ не материализуется,
  но метка far сдвинута: проверка дампом не нужна — слоты на far считают
  от виртуального конца; отдельный сценарий: `H EB $far:1` после DBZ).
- Проверяет: K1-A004, K1-A010 (виртуальный курсор).

## T-M6-11 — комментарии и пустые строки

- Шаги: `t.brick` с `;`-комментариями, пустыми строками, CRLF.
- Эталон: код 0; результат как без них.
- Проверяет: K1-A001 (строки/комментарии), CRLF.

## T-M6-12 — ошибка: строчная hex-цифра

- Шаги: `t.brick` = `H 48 8d\n`
- Эталон: `U-L1-BRICK ERR=FORMAT AT=0001` + CRLF; код 6.
- Проверяет: K1-T002 (ЗАГЛАВНЫЕ), номер строки в ошибке (K1-G003).

## T-M6-13 — ошибка: дубликат метки

- Шаги: `t.brick` = `:a\n:a\n`
- Эталон: ERR=FORMAT AT=0002; код 6.
- Проверяет: K1-N001 (дубликат).

## T-M6-14 — ошибка: неопределённая метка

- Шаги: `t.brick` = `H 74 $zz:1\n`
- Эталон: ERR=FORMAT AT=0001; код 6.
- Проверяет: K1-N002 (−1 → fail_format).

## T-M6-15 — ошибка: ссылка не в конце строки

- Шаги: `t.brick` = `H 48 $x 90\n`
- Эталон: ERR=FORMAT AT=0001; код 6.
- Проверяет: контракт SPEC/08 (слот — последний элемент).

## T-M6-16 — файловые ошибки

- Шаги: `brick.exe nosuch.brick t.bin` (несуществующий вход);
  `brick.exe <имя из 128+ символов>.brick t.bin`.
- Эталон: `U-L1-BRICK ERR=OPEN SRC` + CRLF, код 4;
  `U-L1-BRICK ERR=LONG NAME` + CRLF, код 3.
- Проверяет: K1-F001 (−1), K1-C005 (предел 127), errtab-индексы K1-G001.

## T-M6-17 — пределы: большой исходник и большое тело

- Шаги: `big.brick` из 0x8000 строк `H 90` (больше 128 КиБ);
  `bigout.brick` = `DZ 10000` ×5 (тело больше 64 КиБ).
- Эталон: `U-L1-BRICK ERR=BIG SRC` + CRLF, код 7;
  `U-L1-BRICK ERR=BIG OUT` + CRLF, код 10.
- Проверяет: K1-G001 (обе проверки пределов; ДЗ-пассаж 1 без записи).
