# Тест-план: мост BRIDGE v1 (L5, этап E9.1)

Паспорт файла: TESTS/T-L5-BRIDGE.md | слой: L5 | роль: тест-план моста
EXE -> BRICK v2 + PEG v1 (SPEC/15); якоря и статус секций 18/18b батареи.

## Обязательство

Мост обязан: (1) принимать все образы семейства UNIVERSAL и отказывать
чужим (BridgeError, детерминированно); (2) эмитить BRICK v2 + PEG v1,
круг `enc -> brick -> pegen` над которыми воспроизводит исходный EXE
байт-в-байт; (3) M-строка — только при точном воспроизведении байтов
кодировщиком enc, иначе H-строка (байты те же).

Свидетели (тройные, как секции 14-17): оракул `LAB/py/lab_bridge.py`
(семантика SPEC/15) == якоря `LAB/py/lab_bridge_cases.py` (ручные
литералы, сверены с KERNEL/L0-SEED/BYTECODE.md) == ИНСТРУМЕНТЫ
(enc.exe -> brick.exe -> pegen.exe, эмуляция LAB; T-E9-15/16).
С E9.3 — четвёртый свидетель: СТАТИЧЕСКИЕ якоря-файлы
`KERNEL/<м>/<имя>.anchor.b2` + `.anchor.peg` (12 артефактов; генератор
`LAB/ai/anchor_gen.py`, проверка T-E9-25 — SPEC/15 п. 11).
