### K5-G002 — emit_peg

| Поле | Значение |
|---|---|
| Слой | L5 |
| Ветвь | G — PEG-выход |
| Файл | bridge_self_g.wall (RVA 1449D) |
| Функция | ДРАЙВЕР PEG-выхода: текст PEG v1 в буфере outmem (переиспользуется после emit_body — текст b2 уже записан в файл; PEG ~130-180 Б с начала: outcur = 0) и запись <выход>.peg == _peg_text оракула (SPEC/15 п. 8): шапка (ptplb + exebuf[77..77+modlen) + «.exe») + !module <имя> + !entry <entryrva> + !idata <rva> <размер> + !iat <rva> <размер> + !bss <n> (если != 0) + !stackcom <n> (если rd32(@0xE8) != 0x1000) + !heapcom <n> (если rd32(@0xF8) != 0x1000) + LF |
| Вход | nlen3 — длина слова-пути <выход>.peg (аргумент 3 CLI) |
| Выход | файл <выход>.peg; коды 8 (ERR=OPEN OUT) / 9 (ERR=WRITE OUT) — CreateFile2 WRITE/CREATE_ALWAYS, как emit_body |
| Состоит из | K5-E002 app_ch, K5-E004 copy_str, K5-E008 out_hexv (ветвь E); K5-P002 rd32, K5-C005 widen (чтения полей по фиксированным смещениям SPEC/04: idata @272/@276, iat @360/@364, stackcom @232, heapcom @248); глобали entryrva/bss/modlen |
| Используется в | main (после emit_body, до print_facts) |
| Тест | T-E9-24, T-E9-23 |
| Статус | готов |

> Опциональные директивы — только в хвосте (bss/stackcom/heapcom):
> порядок строк фиксирован, каждая — литерал-префикс (s_pm..s_ph,
> начинающийся с LF кроме первой) + значение; завершающий LF один.
> Числа — out_hexv (ЗАГЛАВНЫЙ hex без ведущих нулей) == «%X» оракула.
