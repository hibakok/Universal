# M3-UNIVM-V — карточки ветви V (интерпретатор ядра UNIVM, 14)

Паспорт файла: MAP/M3-UNIVM-V.md | слой: L3 | роль: карточки ветви V —
интерпретатор ядра UNIVM (выделена из MAP/M3-UNIVM.md по лимиту 500
строк; прецедент — M1-ENC-E/M1-ENC-S).
Формат карточки — SPEC/01-METHOD-CARD.md; указатель — MAP/METHODS.md.

> Ветвь V — цикл интерпретатора и кирпичи опкодов: K3-V001 interp
> (финал E7.2: предел шагов trap 6 ДО выборки + порядок проверок
> SPEC/12 п. 7 + диспетчер всех 18 опкодов), K3-V002 op_halt,
> K3-V003 fail_trap (диагностика TRAP/STEPS), K3-V101..V111 —
> по кирпичу на опкод 01..0B (const/mov/ALU). Карта RVA —
> KERNEL/L3-UNIVM/BYTECODE.md §2; остальные ветви — MAP/M3-UNIVM.md.

## Ветвь V — интерпретатор

### K3-V001 — interp

| Поле | Значение |
|---|---|
| Слой | L3 (исходник — WALL) |
| Ветвь | V — интерпретатор |
| Файл | kernel_self_vm.wall (RVA 589D) |
| Функция | Цикл интерпретатора — ФИНАЛ этапа E7.2 (все 18 опкодов); порядок проверок SPEC/12 п. 7: (0) предел шагов — steps >= steplim → ловушка 6 (ДО выборки pc — как оракул run(max_steps); глобаль steplim задаёт K3-C008); (1) pc за кодом → ловушка 2; (2) опкод вне 01..12 → ловушка 1; (3) длина: F1 (3 Б) для 02..0B, F2/F3 (6 Б) для остальных — pc+длина за кодом → ловушка 2; (4)(5) — в кирпичах опкодов: 01..0B → op_const..op_eq, 0C..0F → op_ldb..op_stq (ветвь M), 10..11 → op_jmp/op_jnz (ветвь J), 12 → op_halt |
| Вход | глобали codebuf/codesize/pc/steps/steplim/regs[16] |
| Выход | останов через op_halt/fail_trap (ловушки 1-4, 6); шаги — в глобали steps |
| Состоит из | K3-V101..K3-V111, K3-M101..M104, K3-J101..J102, K3-V002, K3-V003 |
| Используется в | K3-X001 |
| Тест | T-E7-12/13/15/16/17/18 |
| Статус | готов (финал E7.2) |
