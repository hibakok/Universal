# M3-UNIVM-V — карточки ветви V (интерпретатор ядра UNIVM, 19)

Паспорт файла: MAP/M3-UNIVM-V.md | слой: L3 | роль: карточки ветви V —
интерпретатор ядра UNIVM (выделена из MAP/M3-UNIVM.md по лимиту 500
строк; прецедент — M1-ENC-E/M1-ENC-S).
Формат карточки — SPEC/01-METHOD-CARD.md; указатель — MAP/METHODS.md.

> Ветвь V — цикл интерпретатора и кирпичи опкодов: K3-V001 interp
> (срез E7.4-2b: предел шагов trap 6 ДО выборки + порядок проверок
> SPEC/12 п. 7 + диспетчер v0 01..12 + v1 ALU 13..16), K3-V002
> op_halt, K3-V003 fail_trap (диагностика TRAP/STEPS), K3-V101..V111
> — по кирпичу на опкод 01..0B (const/mov/ALU v0; часть
> kernel_self_vm.wall), K3-V112..V116 — срез E7.4-2b (часть
> kernel_self_alu.wall): фундамент udivmod + опкоды 13..16
> (mul/div/mod/sra + ловушка 7). Карта RVA — KERNEL/L3-UNIVM/
> BYTECODE.md §2; остальные ветви — MAP/M3-UNIVM.md.

## Ветвь V — интерпретатор

### K3-V001 — interp

| Поле | Значение |
|---|---|
| Слой | L3 (исходник — WALL) |
| Ветвь | V — интерпретатор |
| Файл | kernel_self_vm.wall (RVA 589D) |
| Функция | Цикл интерпретатора (срез E7.4-2b — v0 01..12 + v1 ALU 13..16); порядок проверок SPEC/12 п. 7: (0) предел шагов — steps >= steplim → ловушка 6 (ДО выборки pc — как оракул run(max_steps); глобаль steplim задаёт K3-C008); (1) pc за кодом → ловушка 2; (2) опкод вне 01..16 → ловушка 1 (17/18 — call/ret, заглушки до среза E7.4-2c); (3) длина: F1 (3 Б) для 02..0B и 13..16, F2/F3 (6 Б) для остальных — pc+длина за кодом → ловушка 2; (4)(5) — в кирпичах опкодов: 01..0B → op_const..op_eq, 0C..0F → op_ldb..op_stq (ветвь M), 10..11 → op_jmp/op_jnz (ветвь J), 12 → op_halt, 13..16 → op_mul/op_div/op_mod/op_sra (часть alu) |
| Вход | глобали codebuf/codesize/pc/steps/steplim/regs[16] |
| Выход | останов через op_halt/fail_trap (ловушки 1-4, 6, 7); шаги — в глобали steps |

### K3-V112 — udivmod

| Поле | Значение |
|---|---|
| Слой | L3 (исходник — WALL) |
| Ветвь | V — фундамент ALU v1 (срез E7.4-2b) |
| Файл | kernel_self_alu.wall (RVA 439B) |
| Функция | БЕЗЗНАКОВОЕ деление 64-битных слов a div b / a mod b (b ≠ 0 — предусловие, проверяет вызывающий кирпич) из простых операций WALL (деление WALL знаковое — idiv): беззнаковое сравнение — переворот знакового бита (x ^ s) >= (y ^ s) знаково (s = 1 << 63 — литералей > 2^31-1 в WALL нет); путь b > 2^63 (b ^ s > 0 знаково) — частное 0/1 без цикла (a < 2^64 <= 2b; в цикле r << 1 переполнило бы 64 бита); путь b <= 2^63 — восстанавливающее деление бит за битом (64 итерации: r = 2r + бит a; r >= b беззнаково → r -= b, бит частного 1; инвариант r < b <= 2^63 — переполнения сдвига нет) |
| Вход | a, b — 64-битные слова (битовые образы) |
| Выход | глобали uq (частное), ur (остаток) — один фундамент на op_div/op_mod |
| Состоит из | — (сдвиги/битовые/вычитание WALL) |
| Используется в | K3-V114, K3-V115 |
| Тест | T-E7-33 (косвенно; фаззи-прототип — LAB/ai/probe_e742b.py, 139 случаев) |
| Статус | готов (E7.4-2b) |
