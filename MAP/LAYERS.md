## Правила слоёв

1. Зависимости только вниз: слой N использует слои < N и никогда наоборот.
2. Каждому слою — свои форматы и реестры; чужие форматы не переиспользуются.
3. Переход на следующий слой разрешён только после самохостинга
   инструментария текущего (кроме L0 — он стартует вручную по определению).
4. Ветви кода живут внутри слоя; сквозные ветви запрещены.

## Текущее состояние (обновлять при изменении)

- L0: 5 модулей (M0-SEED, M0-SEED2, M0-HXDUMP, M0-HEXGEN, M0-PEGEN),
  116 кирпичей, 5 артефактов (seed.exe — 1024 Б; seed2.exe — 2048 Б;
  hxdump.exe — 3584 Б; hexgen.exe — 2560 Б — ATOM → тело; pegen.exe —
  4096 Б — тело + PEG → EXE, собирает сам себя).
- L1: 3 модуля (M1-BRICK, M1-ENC, M1-SPLICE), 132 кирпича; конвейер
  `splice -> enc -> brick -> pegen` самохостится на разрезах (E5/E6.2/E6.3).
- L2: язык WALL v1: оракул (E6.4a) + инструмент M2-WALL (E6.4b,
  66 кирпичей): wall.exe == оракулу на 10 якорях + 26 ошибках +
  big_source; круг WALL -> EXE -> эмуляция «U-WALL-OK 37». Дальше:
  рост языка до v2 (E6.4c) и самохостинг wall.wall (E6.4d).
- Импорты kernel32.dll: GetStdHandle, WriteFile, ExitProcess,
  GetCommandLineA, CreateFileA, ReadFile, CloseHandle.
- L3: 2 модуля (M3-UNIVM — ядро kernel.exe; M3-UVA — ассемблер
  uva.exe): ЭТАП 7 ЗАКРЫТ (E7.4-4): ISA v0+v1 — 24 опкода, стек
  вызовов 1024, ловушки 1-5/7, .UP v1/v2 (секция данных);
  uva.exe == классу оракула байт-в-байт, kernel.exe — диффтест ==
  оракулу на полном корпусе (T-E7-25/24).
- L4: 1 модуль (M4-LIB — библиотека): SPEC/14 + оракул LAB/py/lab_l4.py
  + якоря lab_l4_cases.py + секция 16 батареи (T-E8-01..07, E8.1);
  E8.2a — ветвь C ГОТОВА: lib_c.uva (4 кирпича) + CARD.md +
  диффтесты T-E8-08..11; E8.2b — ветвь N ГОТОВА: lib_n.uva (3
  кирпича; стек-слоты [sp-8,sp); зависимость N→C) + диффтесты
  T-E8-12..16 (вкл. круг с ДВУМЯ частями); E8.2c — ветвь S ГОТОВА:
  lib_s.uva (2 кирпича; АВТОНОМНАЯ ветвь — без зависимостей и без
  стека) + диффтесты T-E8-17..21 (вкл. композицию ТРЁХ ветвей
  C+N+S и круг с ОДНОЙ частью); E8.2d — ветвь M ГОТОВА: lib_m.uva
  (2 кирпича; автономная как S — без зависимостей, стека и консоли)
  + диффтесты T-E8-22..26 (вкл. композицию ЧЕТЫРЁХ ветвей C+N+S+M
  с проверкой ВСЕЙ RAM и круг с ОДНОЙ частью) — СЛОЙ LIB-1
  РЕАЛИЗОВАН ЦЕЛИКОМ (11/11 кирпичей). Демо-программы DoD —
  срез E8.3.
- Виртуальные нули (bss): впервые в M0-HEXGEN — SizeOfRawData < VirtualSize
  (см. SPEC/04-PE-MINIMAL.md).
- Использованных мнемоник x86-64: 14 в M0-SEED, 20 в M0-SEED2,
  24 в M0-HXDUMP, 22 в M0-HEXGEN (реестр форм — SPEC/05-X86-SUBSET.md).
