# Реестр слоёв

Паспорт файла: MAP/LAYERS.md | слой: все | роль: слои абстракции и их статус.

| Слой | Имя | Суть | Статус |
|---|---|---|---|
| L0 | МАШИНА | Ручной машинный код x86-64, формат ATOM (телесная форма), PE32+. Конвейер E4: hexgen (текст → тело) + pegen (тело + PEG → EXE); виртуальные нули bss допустимы. | **в работе** (M0-SEED, M0-SEED2, M0-HXDUMP, M0-HEXGEN, M0-PEGEN готовы) |
| L1 | СБОРКА | Формат BRICK: метки, имена, расчёт rip-смещений автоматически. Ассемблер, написанный машинным кодом, собирает сам себя. | план (этап E5) |
| L2 | ЯЗЫК | Компилируемый язык высокого уровня: переменные, функции, условия, циклы, модули. | план (этап E6) |
| L3 | ВИРТМАШИНА | UNIVM: собственный ISA, виртуальная память, устройства; ядро запускает внешние программы .UP по пути. | план (этап E7) |
| L4 | БИБЛИОТЕКА | Переиспользуемые кирпичи для UNIVM: математика, строки, окна, растр, ввод-вывод. | план (этап E8) |
| L5 | МОСТЫ | Трансляторы EXE -> ATOM (чужой код входит в наш мир) и ATOM -> EXE. | план (этап E9) |
| L6 | ПРОЕКТЫ | Внешние программы: копия Minecraft, AGI, любые другие. Живут в PROJECTS/. | план (этап E10+) |

## Правила слоёв

1. Зависимости только вниз: слой N использует слои < N и никогда наоборот.
2. Каждому слою — свои форматы и реестры; чужие форматы не переиспользуются.
3. Переход на следующий слой разрешён только после самохостинга
   инструментария текущего (кроме L0 — он стартует вручную по определению).
4. Ветви кода живут внутри слоя; сквозные ветви запрещены.

## Текущее состояние (обновлять при изменении)

- L0: 5 модулей (M0-SEED, M0-SEED2, M0-HXDUMP, M0-HEXGEN, M0-PEGEN),
  116 кирпичей, 5 артефактов (seed.exe — 1024 Б; seed2.exe — 2048 Б;
  hxdump.exe — 3584 Б; hexgen.exe — 2560 Б — ATOM → тело; pegen.exe —
  4096 Б — тело + PEG → EXE, собирает сам себя).
- Импорты kernel32.dll: GetStdHandle, WriteFile, ExitProcess,
  GetCommandLineA, CreateFileA, ReadFile, CloseHandle.
- Виртуальные нули (bss): впервые в M0-HEXGEN — SizeOfRawData < VirtualSize
  (см. SPEC/04-PE-MINIMAL.md).
- Использованных мнемоник x86-64: 14 в M0-SEED, 20 в M0-SEED2,
  24 в M0-HXDUMP, 22 в M0-HEXGEN (реестр форм — SPEC/05-X86-SUBSET.md).
