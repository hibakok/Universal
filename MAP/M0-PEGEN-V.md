# Реестр кирпичей модуля M0-PEGEN — ВЕТВЬ v2 (E9.4-4b-4)

Паспорт файла: MAP/M0-PEGEN-V.md | слой: L0 | роль: карточки кирпичей
ветви PEG v2 модуля M0-PEGEN (разрез MAP/M0-PEGEN.md по лимиту 500 строк,
прецедент MAP/M5-BRIDGE-D.md; карточки v1 — там же).

Формат карточки: `SPEC/01-METHOD-CARD.md`. Идентификаторы вечны и не
переиспользуются (правило R5). Общий указатель реестра — `MAP/METHODS.md`.

Ветвь v2 (порт wrap2 — оракул lab_pegen.wrap2, SPEC/07 «Рост v2»):
развилка версий по первой директиве !pev2 (сниффер K0-Q012 перехватывает
вызов parse_peg в dispatch @0175), разбор директив, сборка образа из
нулей + патчей с САМООПИСАНИЕМ области заголовков. Код в конце файловой
части — существующий код и данные v1 не сдвинуты.

E9.5-1a (сессия 89): ПРЕДЕЛЫ ПОДНЯТЫ (outbuf 0x400000, спаны 256,
записи 16384, секданные 0x100000 — константы листинга
LAB/ai/pegen_v2_code.py); ветвь ПЕРЕИЗЛУЧЕНА (SPANMAX=256 — imm32,
форма 4 -> 7 Б; исправления hex_blob/do_hdr — см. SPEC/07 «Дефекты»);
адреса кирпичей Q017+ сдвинуты (карта — BYTECODE.md); bss: filebuf
0x400000 / imagebuf 0x100000 (v1, диспетчер G041) — rip-ссылки v1
переточены (pegen_build_e95.py). Все адреса — телесные (RVA = +0x1000).

Слой всех кирпичей — L0. Регистры при соглашении вызовов: RBX — база
образа (не портится); RSI — курсор текста; R12..R15 — сохраняемые
времена внутри кирпичей; волатильные — черновые.
