# Реестр M1-ENC — служебные ветви (H/U/F/D)

Паспорт файла: MAP/M1-ENC-S.md | слой: L1 | роль: карточки служебных ветвей модуля M1-ENC (печать, файлы, данные).

Формат карточки: `SPEC/01-METHOD-CARD.md`. Смещения — телесные (RVA = +0x1000); полная карта — `KERNEL/L1-ENC/BYTECODE.md` §3. Ветви потока/разбора — `MAP/M1-ENC.md`; кодирование — `MAP/M1-ENC-E.md`.

## Ветвь H — hex-вывод номера строки

### K1-H011 — hex16_to_4

| Поле | Значение |
|---|---|
| Слой | L1 |
| Ветвь | H |
| Файл | KERNEL/L1-ENC/enc.b2, тело 0x2133 |
| Функция | Число ≤ 0xFFFF -> 4 hex-цифры в [RDI] |
| Вход | EAX = число; RDI = приёмник |
| Выход | 4 цифры; RDI += 4 |
| Состоит из | — (реинкарнация K1-H001 с фиксацией E5a) |
| Используется в | K1-G013 |
| Тест | T-E6-07, T-E6-11 |
| Статус | готов |
