# Реестр кирпичей модуля M0-SEED

Паспорт файла: MAP/M0-SEED.md | слой: L0 | роль: карточки кирпичей модуля M0-SEED.

Формат карточки: `SPEC/01-METHOD-CARD.md`. Идентификаторы вечны и не
переиспользуются (правило R5). Общий указатель реестра — `MAP/METHODS.md`.

С этапа E4 листинги модулей ведутся в телесной форме (смещение 0 =
RVA 0x1000): смещения `@…` в карточках сдвинуты на −0x200 относительно
старых файловых (заголовки генерирует pegen — SPEC/07).

### K0-X001 — prepare_stack

| Поле | Значение |
|---|---|
| Слой | L0 |
| Ветвь | X — старт и выход |
| Файл | KERNEL/L0-SEED/seed.hex, @0000 |
| Функция | Готовит стек к вызовам Win64: тень 0x20 + выравнивание 16 |
| Вход | — (выполняется первым в точке входа) |
| Выход | RSP уменьшен на 0x28; RSP % 16 == 0 |
| Состоит из | — (атомарный) |
| Используется в | M0-SEED (вход) |
| Тест | T-M0-02, T-M0-03 |
| Статус | готов |

### K0-S002 — read_sizeofimage

| Поле | Значение |
|---|---|
| Слой | L0 |
| Ветвь | S — самопознание образа |
| Файл | KERNEL/L0-SEED/seed.hex, @000B, @000E, @0012 |
| Функция | Читает из собственного PE-заголовка размер образа (SizeOfImage) |
| Вход | RBX = база образа (от K0-S001) |

| Используется в | K0-H001 |
| Тест | T-M0-04 |
| Статус | готов |

### K0-H001 — hex32_to_ascii8

| Поле | Значение |
|---|---|
| Слой | L0 |
| Ветвь | H — шестнадцатеричное представление |
| Файл | KERNEL/L0-SEED/seed.hex, @0014..@0040 |
| Функция | Превращает 32-битное число в 8 ASCII-цифр hex (старшая слева) |
| Вход | EAX = число; RSI = адрес поля 8 байт; R8 = таблица 16 цифр ASCII |
| Выход | поле [RSI..RSI+8) заполнено; EAX сохранён (цикл rol замкнут); RSI += 8 |
| Состоит из | K0-S002 (источник числа) |
| Используется в | K0-P001 |
| Тест | T-M0-02, T-M0-04 |
| Статус | готов |

### K0-P001 — write_stdout

| Поле | Значение |
|---|---|
| Слой | L0 |
| Ветвь | P — печать |
| Файл | KERNEL/L0-SEED/seed.hex, @0042..@006F |
| Функция | Пишет строку байтов в стандартный вывод (консоль) |
| Вход | RDX = адрес буфера; R8D = длина; стек подготовлен (K0-X001) |
| Выход | байты в stdout; RAX = результат WriteFile; written обновлён |
| Состоит из | GetStdHandle, WriteFile (импорты kernel32.dll) |
| Используется в | M0-SEED (главный поток) |
| Тест | T-M0-02 |
| Статус | готов |
