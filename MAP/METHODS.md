# Реестр кирпичей

Паспорт файла: MAP/METHODS.md | слой: все | роль: карточки всех методов проекта.

Формат карточки: `SPEC/01-METHOD-CARD.md`. Идентификаторы вечны и не
переиспользуются (правило R5). Поиск: по ID или по слову в «Функция».
