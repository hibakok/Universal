# Реестр M1-SPLICE — карточки кирпичей (ветви X/C/G/S/N/H/U/F/D)

Паспорт файла: MAP/M1-SPLICE.md | слой: L1 | роль: карточки кирпичей M1-SPLICE.

Формат карточки: `SPEC/01-METHOD-CARD.md`. Смещения — телесные (RVA = +0x1000);
полная карта — `KERNEL/L1-SPLICE/BYTECODE.md` §3. Исходник разрезан по
`!include` (SPEC/10): корень `splice.b2` + `splice_s.b2` + `splice_svc.b2` +
`splice_data.b2`.
