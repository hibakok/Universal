# M5-BRIDGE — карточки кирпичей моста, часть 4 (ветвь L — 17, E9.2-3b;
файлы-части l/l2)

Паспорт файла: MAP/M5-BRIDGE-L.md | слой: L5 | роль: реестр кирпичей
меток/семантики/драйвера эмиссии моста M5-BRIDGE (продолжение
MAP/M5-BRIDGE-E.md — разрез по лимиту 500 строк). Формат карточки —
SPEC/01-METHOD-CARD.md; указатель — MAP/METHODS-2.md.

> Ветвь L (ДВЕ ЧАСТИ — разрез по лимиту 500 строк):
> bridge_self_l.wall — КАРТЫ И СЕМАНТИКА (K5-L001..L010, L016);
> bridge_self_l2.wall — РЕНДЕР И ДРАЙВЕР (K5-L011..L015, L017).
> Режим "H" оракула
> lab_bridge._emit_lines): метки l/d/iat_ (приоритет iat_ > l > d;
> правило представимости — метка невозможна строго внутри выжившей
> инструкции), семантика DD/DQ импортов с $ссылками (приёмка строк
> без пересечений с инструкциями/друг другом/метками внутри), разрезы
> «:имя ; @смещ» и ДРАЙВЕР эмиссии emit_body (линейный проход по
> событиям [0, target): метка/семантика/H-строка/данные). Семантика —
> SPEC/15 п. 6/8; эквивалентность оракулу — T-E9-22 (12 артефактов +
> синтетика, вкл. вырожденные hint-ins/imp0), круг инструментами —
> T-E9-23. Примитивы вывода — ветвь E; декодер — D; спуск — W.

### K5-L001 — imp_hints

| Поле | Значение |
|---|---|
| Слой | L5 (исходник — WALL) |
| Ветвь | L — метки/семантика |
| Файл | KERNEL/L5-BRIDGE/bridge_self_l.wall (RVA A1F8) |
| Функция | Перечитать записи таблицы thunk (INT/IAT, счёт impn) → кучи hhrv/hno/hnl: маскированный u64 записи, файловое смещение имени (rva_file ПО ВСЕМ СЕКЦИЯМ — E9.4-4b-2: чужие импорты вне тела секции кода; для семьи == rva_off), длина имени |
| Вход | глобали thunk (RVA таблицы), impn, exebuf/exelen/rawptr |
| Выход | hhrv[k] (0..2^63-1 — бит 63 снят), hno[k] (файловое смещение hint-RVA+2; -1 = вне файла → имя «?»), hnl[k] (quirk C-строки cstr_len) |
| Состоит из | u64 (K5-D015), cstr_len (K5-P014) |
| Используется в | K5-L004, K5-L007, K5-L016 |
| Тест | T-E9-22 |
| Статус | готов |

> Маска бита 63: отрицательное значение u64 в ЗНАКОВОЙ qword-арифметике
> WALL = бит 63 установлен → достаточно v + 2^63 (16777216*256*
> 16777216*128). СРАВНИВАТЬ v >= 2^63 НЕЛЬЗЯ: произведение представимо
> только как -2^63, сравнение всегда истинно (урок E9.2-3b, дефект №1).
