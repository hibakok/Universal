# M4-LIB. Карточки кирпичей библиотеки L4

Паспорт файла: MAP/M4-LIB.md | слой: L4 | роль: карточки кирпичей модуля
M4-LIB — библиотека переиспользуемых кирпичей для UNIVM-программ.

## Обязательство модуля

Реализация каждого кирпича (части `KERNEL/L4-LIB/lib_*.uva`, срезы
E8.2+) обязана совпадать с оракулом `LAB/py/lab_l4.py` по наблюдаемому
поведению (консоль, RAM, регистры) на корпусе якорей
`LAB/py/lab_l4_cases.py` (SPEC/14 п. 6). Карточки созданы ДО кода
(правило R3, статус `план`); ABI — SPEC/14 п. 3 (аргументы r1..r4,
результат r1, временные r1..r4, сохраняемые r5..r12/sp=r13/devbase=
r14/r15; вызов `call lib_<имя>`).

Ветви: **C** — консоль (4), **N** — числа (3), **S** — строки (2),
**M** — память (2). Итого 11 кирпичей (слой LIB-1, SPEC/14 п. 4).
