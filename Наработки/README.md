# Наработки — папка незавершённых задач

Паспорт файла: Наработки/README.md | зона: рабочая | роль: конвенция
папки наработок (введена сессией 89).

## Правила

1. Папка содержит материалы ТОЛЬКО выполняемой прямо сейчас задачи,
   которая не закрыта за один присест. Материал накапливается от
   сессии к сессии, пока задача не решена.
2. Каждый набор наработок обязан иметь файл-маркер
   `Наработки/<ИМЯ-ЗАДАЧИ>.md`: к какой задаче относятся наработки,
   что уже сделано, что осталось, какие файлы здесь лежат и что они
   значат. Любой ИИ, открывший репозиторий, читает маркеры и понимает
   состояние без разбора всей папки.
3. Материал покидает папку, когда он ГАРАНТИРОВАННО работоспособен и
   выполняет возложенную функцию: код встраивается в проект (или
   становится инструментом LAB/ai), знания — в документы (SPEC/DOCS/
   MAP/TESTS), планы — в DOCS/03-ROADMAP.md. После этого папка
   очищается (ценное изъято, остальное удалено).
4. Папка НЕ является частью системы UNIVERSAL: она не участвует в
   сборке и тестах; её содержимое не импортируется кодом KERNEL/LAB.
5. Если папка ПУСТА (кроме README) — активных незавершённых задач
   нет; следующий шаг — очередь `DOCS/03-ROADMAP.md`.
