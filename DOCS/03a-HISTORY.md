### E6.4g-5 — предел ВХОДА enc 1 МиБ -> 2 МиБ (сессия 35)

Мотив: .b2 каркаса wall.wall 879662 Б = 84% предела 1 МиБ — срезы
C-2/2+ прохода 2 эмитции не поместятся; предписано журналом сессии 34
как первое действие перед C-2/2.

- enc.b2 — 2 imm32 (вместимость/предел 0x100000 -> 0x200000, той же
  длины) + комментарии; enc_data.b2 — DBZ filebuf 0x100100 -> 0x200100
  (2 МиБ + сентинел), outbuf 0x220080 -> 0x440100 (х2; оценка выхода
  вход x 23/11 + 1 = 0x42E9DB для 2 МиБ — запас 0x11725).
- Пересборка оракулами (НОВЫЙ dev LAB/ai/enc_build_lim3.py): тело
  0x2CCE и файл 12288 Б НЕ ИЗМЕНИЛИСЬ (всего 6 байтов diff: 2 imm32 +
  1 disp32 lea outbuf — единственная rip-ссылка, буфер сдвинулся
  +0x100000 — и 3 байта PE-заголовка); !bss 0x323286 -> 0x643306,
  vsize 0x325F54 -> 0x645FD4, SizeOfImage 0x327000 -> 0x647000;
  SHA EEF6C66E… -> B4B49041…; enc.brick 76268 Б; метки/импорты не
  тронуты (idt 0x3BB3/iat 0x3BDB).
