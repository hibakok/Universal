# 03. Дорожная карта

Паспорт файла: DOCS/03-ROADMAP.md | слой: все | роль: этапы развития и критерии готовности.

Принцип: **малые шаги**. Каждый этап — одна короткая итерация с проверяемым
результатом. Следующий этап начинается только после полного выполнения
критериев готовности (DoD) предыдущего.
