## Сессия 87 — 2026-11-28 — E9.4-4b-4: ПОРТ wrap2 (PEG v2) В pegen.exe

Состояние на входе: E9.4-4b-3 закрыт (сессия 86; батарея 242/242 —
группы 1|4, CI на пуше). Очередь (SPEC/07 «Рост v2»; ROADMAP):
E9.4-4b-4+ — порт wrap2 в pegen.exe (L0 — ручной машинный код ATOM);
затем первый чужой круг (DoD E9.4). Оракул wrap2 закреплён якорями
T-E9-30 (E9.4-3c-1) — «оракул впереди».

Что сделано: (1) ВЕТВЬ v2 В ТЕЛЕ pegen — 12 кодовых кирпичей
(Q012..Q019, E005..E007, G043) + 2 данных (D047 v2kwtab/строки, D048
ячейки/буферы): развилка версий sniff_v2 (первая директива !pev2 ->
v2, иначе — v1), разбор директив v2 (блоб hex_blob с пределом записи,
спан/сек-таблицы с попарными проверками наложений), самоописание
области заголовков (MZ/PE/таблица/raw/filesz), применение тела и
патчей, ОДНА запись out.exe; отказы — ERR=FORMAT 9 БЕЗ частичных
выходов. Код ПРИПИСАН в конец файловой части (тело 0x0D7A..0x152F,
1944 Б, 510 инструкций) — существующий код и данные v1 НЕ сдвинуты.
(2) КОМПОНОВКА bss: сдвиг +0x7CA (длина нового блока); 58 rip-ссылок
старого КОДА на bss (обход ПО ДЕКОДИРОВАНИЮ lab_x86 — без ложных
срабатываний в данных) + 12 nonzero-RVA vdesc переточены disp32 += delta;
вызов parse_peg @0175 -> sniff_v2. (3) Данные: v2kwtab (4 RVA + строки
pev2/hdr/body/sec) в файловой части; НОВЫЙ bss: 15 ячеек + outbuf
0x40000 + spantab 64x8 + sectab 128x16 + secdata 0x2000 + rawtab
0x8000; pegen.peg: !bss 30402 -> 7AE3E. (4) ПРЕДЕЛЫ ИНСТРУМЕНТА
(SPEC/07 «Ограничения v2 — инструмент»; оракул пределов не имеет):
H <= 0x40000 и файл <= 0x40000 (outbuf), !hdr <= 64, !sec <= 128,
сек-данные <= 8 КиБ, rawtab 4096 — снять при первом чужом круге.
(5) Инструменты LAB/ai: pegen_v2_asm.py (мини-ассемблер e4_ledger:
ручные формы, компоновка лишь разрешает rip-смещения/длины; round-trip
контроль обратным декодированием lab_x86) + pegen_v2_code.py /
pegen_v2_code2.py (листинг; разрез по лимиту 500) + pegen_build_v2.py
(патчер + сборка + hex-регенерация с сохранением комментариев строк).
(6) Тесты: НОВЫЙ T-M5-18 (секция 8d батареи, lab_t_pegen2.py): ПОРТ —
2 чужих крафта (тела target + якорные тексты FOREIGN_PEG2/FOREIGN2_PEG2)
— pegen.exe под эмуляцией == wrap2 байт-в-байт; ОТКАЗЫ — 26
(19 мутантов якоря + 5 синтетик _synth + v1-граница) — код 9 ==
ValueError оракула. Зонд pegen_v2_probe.py: круг E4 самосборки +
регресс 9 модулей + ПОРТ + отказы + сценарии v1 — 7/7. Батарея:
SHA pegen в lab_verify.py обновлён (D1547D93…CFFBD); группы 1|4 —
138/138 + 31/31 (244 проверки). (7) Якорь pegen регенерирован
(anchor_gen.py: M=855 H=195; 11 прочих — без изменений; T-E9-25 — 24
файла сходятся). (8) Артефакты: pegen.exe 0x1800 Б (6144), тело 0x1544,
vsize 0x7C382, SHA-256 D1547D93…C785CFFBD. (9) Документы: SPEC/07
(порт выполнен + ограничения инструмента), ROADMAP (4b-4 [x]; очередь
4b-5+ — первый чужой круг), CARD/BYTECODE/VERIFY (журнал + 7 пойманных
классов ошибок компоновки), MAP/M0-PEGEN-V.md (14 карточек — разрез
M0-PEGEN.md по лимиту 500) + METHODS (указатель), T-L0-PEGEN (T-M5-18),
INDEX/INDEX-LAB, LAB/README, README, JOURNAL (эта запись).

Проверки (все зелёные): зонд 7/7; батарея группами 1|4 (138/138 +
31/31); якоря 24/24 (группа 4). Поймано и закрыто 7 КЛАССОВ ошибок
компоновки (VERIFY.md v2-журнал: modrm-поля r8-r15, disp от
фиксированной длины, mov вместо add, reg-reg через rip-форму, пропуск
skip_spaces перед блобами, RVA без базы 0x1000, 64-битные чтения
32-битных полей) — все пойманы эмуляцией/round-trip ДО выгрузки.

Решения (чтобы не переделывать): (1) код v2 ПРИПИСАН в конец — адреса
v1 стабильны; bss сдвигается и перетачивается декодер-обходом (данные
не сканируются — ложных патчей нет); (2) развилка — ПАТЧ ВЫЗОВА @0175
(4 байта rel32), а не вставка в середину тела; (3) !hdr-патчи
применяются ПРЯМО В outbuf при разборе (H известен первой директивой);
спаны хранятся только для проверок наложений; !sec-блобы — в secdata
(rp секций ещё неизвестен — самоописание после разбора); (4) outbuf —
bss (нули при загрузке: gaps не требуют memset; одна сборка на
процесс); ОДНА запись [0, filesz) — как v1-конвейер заголовок/тело/
дозапись, но одним блоком; (5) hex_blob получает ПРЕДЕЛ r8 — общая
защита и для outbuf+H, и для secdata+0x2000; (6) 32-битные поля
читаются ТОЛЬКО 32-битными формами (эмулятор обнуляет старшие при
32-битных записях, но 64-битное чтение соседей хватало бы мусор).
Следующий срез E9.4-4b-5+: ПЕРВЫЙ ЧУЖОЙ КРУГ (DoD этапа E9.4) +
подъём пределов инструмента по потребностям круга.
