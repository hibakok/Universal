## Сессия 85 — 2026-11-25 — E9.4-4b-2: ПОРТ ЭМИССИИ b2 ЧУЖОГО ТЕЛА

Состояние на входе: E9.4-4b-1 закрыт (сессия 84; батарея 242/242 —
группы 1|4, CI на пуше). Очередь (SPEC/15 п. 10): E9.4-4b-2+ — порты
эмиссий чужого пути. Срез 4b-2 — b2 чужого тела (оракул
emit_b2_foreign E9.4-3c-3, канон был закреплён ДО порта — «оракул
впереди»); PEG v2/wrap2 — срезы 4b-3+.

Что сделано: (1) ВЕТВИ L/M ПАРАМЕТРИЗОВАНЫ base = codevaddr
(прецедент оракула сессии 82 — «base — ПАРАМЕТР, не дубль-фронт»):
имена меток l/d — RVA (emit_labname: off + codevaddr), known-ссылки
emit_dollar (+ codevaddr), hint-смещения и базы импортов (imp_labels/
imp_offs/dq_base: минус codevaddr); у семьи codevaddr == 4096 —
семейный выход не меняется ПОСТРОЕНИЕМ (якоря T-E9-25 — 22 файла
байт-в-байт; якорь bridge регенерирован: M=21694 H=0, инвариант
0 H-строк — хвост 0x69 < 0x200 внутри w1). (2) K5-P021 rva_file —
RVA -> файловое смещение ПО ВСЕМ СЕКЦИЯМ (порт _sec_of/_read_rva
оракула lab_pe E9.4-3a; для семьи тождественно rva_off на
отображаемых RVA — замена в imp_offs/imp_hints нейтральна);
imp_offs: нет дескриптора (DD[1] вне отображения/за файлом) — все
смещения -1 -> impbad (сырые байты). (3) K5-P022 fimp_walk —
обход IDT DD[1] по rva_file: dllcnt (шапка) + дескриптор 1 ->
thunk/impn (терминаторы 20/8 нулей или вне файла — как разбор
оракула; чётность hint и kernel32 — НЕ проверяются: семейная
инвариантность) + K5-P023 count_sects — sectcnt (шапка «секций N»;
слоты за файлом обрывают таблицу). (4) ШАПКА чужого b2 — K5-E019
ftpl_dec/K5-E020 app_ftpl (HEX-литерал s_ftpl 194 Б -> ftplb[25];
первая строка — ОБЩАЯ с семьёй app_tpl(0,54)): «; Исходник: чужой
PE32+ (секций N, DLL N; тело секции кода RVA <hex>, <hex> Б; !bss
<hex>)» / «; Круг: enc -> brick -> тело; wrap2(тело, PEG v2) ==
исходный EXE» == _b2_foreign_text оракула; драйвер
emit_body(nlen2, isf) — развилка шапки при ОБЩЕМ теле прохода.
(5) ЧУЖАЯ факт-строка + ВЫХОД M=/H= (s_f9/s_fa — прецедент
E9.2-3c); main: чужой путь — фронт -> fimp_walk/count_sects ->
спуск -> init_tables -> build_maps -> emit_body(nlen2, 1) ->
print_ffacts; <выход>.peg НЕ создаётся (PEG v2 — срезы 4b-3+).
(6) ОРАКУЛ: защитная ветвь _import_map — pe["imports"] пуст
(DD[1]=0) -> пустые карты (сырые байты; было — IndexError: класс
«нет импортов» не был покрыт крафтами); КОРПУС: foreign_line —
статистика emit_b2_foreign (M=/H=), НОВЫЙ перевёртыш «нет
импортов (DD[1]=0)» (13-й: импорты-как-данные — вызовы через
$d*-метки; T-E9-19: 30 кейсов). (7) Тесты: T-E9-29 — ПОРТ с
t.b2 == emit_b2_foreign байт-в-байт (+факт-строка с M=/H=; t.peg
не пишется); T-E9-19 — перевёртыши: t.b2 == оракулу. (8) Зонд
probe_e94_4b2.py: сборка оракулами + нейтральность 12 + ПОРТ
(2 крафта + 13 перевёртышей) + 7 отказов — 34/34 с первого
прогона. (9) Пересборка: 764055087 + 74025277 + 80441068 + 5046
шагов (resume-срезами; bridge.b2 == оракулу WALL байт-в-байт);
якорь bridge регенерирован (M=21694 H=0); BYTECODE.md —
генератор gen_bytecode_e94_4b2.py (127 функций; 94+2 скаляра;
строки 57). (10) Документы: SPEC/15 п. 10 (контракт E9.4-4b-2),
ROADMAP (E9.4-4b-2 [x]; очередь 4b-3+), CARD/BYTECODE/VERIFY
(журнал), MAP/M5-BRIDGE (P021..P023) + M5-BRIDGE-E (E019/E020) +
M5-BRIDGE-L (параметризация base) + METHODS-2 (128), T-L5-BRIDGE
(порт п. 5 + журнал), DOCS/02, README, LAB/README, INDEX/
INDEX-LAB, JOURNAL (эта запись).

Проверки (все зелёные): зонд 34/34 (нейтральность 12/12; ПОРТ
2+13; отказы 7/7); батарея группами: 1 — 136/136, 4 — 31/31 (вкл.
T-E9-25: якоря 24/24; T-E9-19: 30 кейсов, b2 перевёртышей ==
оракулу; T-E9-29: ПОРТ 2+7/9). Группы 2/3/5 не зависят от
изменённых модулей (lab_bridge/lab_bridge_text/l corpus — только
секции 18*); CI повторит (сборка — T-E9-17: 764 млн шагов wall).

Дефекты: не обнаружено — зонд и батарея зелёные с первого прогона
(канон тела был закреплён оракулом E9.4-3c-3 ДО порта — «оракул
впереди» окупился дважды). Поймана и закрыта ДОРОГАЯ ДЫРА класса:
«нет импортов» (DD[1]=0) — оракул падал IndexError, класс не был
покрыт; теперь защитная ветвь (сырые байты) + 13-й перевёртыш в
T-E9-19 покрывает и оракул, и инструмент (импорты-как-данные:
вызовы через $d*-метки — M=28 H=0 у всех 13).

Решения (чтобы не передумывать): (1) base = codevaddr — ГЛОБАЛЬ
развилки (не новый параметр между функциями): у семьи 4096,
семейный путь не тронут построением; БАЗОЧУВСТВИТЕЛЬНЫЕ места —
только имена меток (RVA) и смещения структур импортов; $base
(телесное -0x1000) и rip-цели декодера — ОТ base НЕ зависят
(телесные смещения; ABI brick SPEC/08 п. 4). (2) rva_file — ОБЩЕЕ
отображение для семЕйных и чужих чтений (не ветвление): для семьи
тождественен rva_off — замена imp_offs/imp_hints НЕЙТРАЛЬНА
построением (одна секция, exelen == rawptr+rawsize). (3) Шапка
чужого b2 — СВОЙ шаблон ftplb (не расширение s_tpl): семейный
контракт заморожен якорями; первая строка переиспользуется из
tplb[0..54] — общий канон. (4) «Нет импортов» — СЫРЫЕ байты (не
отказ): обобщение «импорты вне тела» — семантика п. 6 оракула;
зафиксировано 13-м перевёртышем. (5) Следующий срез E9.4-4b-3:
порт PEG v2 (emit_peg_v2/_fold/_chunks64 — ветвь G) в bridge.exe;
затем wrap2 в pegen.exe — ПЕРВЫЙ ЧУЖОЙ КРУГ (DoD E9.4).
