# ЛАБОРАТОРИЯ ИИ — внешний измерительный прибор репозитория UNIVERSAL

Паспорт файла: LAB/README.md | слой: внешний инструмент | роль: правила лаборатории.

## Статус

`LAB/` — **внешняя лаборатория ИИ**, ведущего разработку репозитория. Она
живёт в репозитории (чтобы не теряться между сессиями), но НЕ является
частью системы UNIVERSAL и не подчиняется правилу R9 (запрет сторонних
языков) — как осциллограф не является частью исследуемой схемы.

- Инструменты написаны на Python 3 (только стандартная библиотека,
  без единого стороннего пакета — дух R9 соблюдён даже здесь).
- Система UNIVERSAL **никогда** не зависит от LAB: ни один файл
  KERNEL/SPEC/MAP/PROJECTS не импортирует и не вызывает LAB.
- LAB — единственное место репозитория, где допустим Python.
- Смена поведения артефактов UNIVERSAL не требует правки LAB (только
  эталонные строки в сценариях, если меняется документированный вывод).

## Назначение

Верификация этапов E0+ без Windows: разбор PE, дизассемблирование,
эмуляция x86-64 с заглушками Win32, оракулы форматов (ATOM, BRICK, PEG),
сквозные круги самосборки. Полностью повторяет три уровня проверки
`SPEC/02-LAYER0-SPEC.md` автоматически.

## Запуск полной батареи

```
python3 LAB/py/lab_verify.py            # из корня репозитория
```

Батарея проверяет: целостность хэшей артефактов, инварианты PE,
эмуляцию всех документированных сценариев TESTS/, равенство
оракулов и инструментов, круги самосборки E4/E5 (на разрезе E6.3),
оракулы ENC и SPLICE, самохостинг E5/E6.2/E6.3. Время — ~32 секунды.
Итог: `OK n/m` (код 0) или список провалов (код 1).

## Правила лаборатории

1. Файл — не более 500 строк; кирпичная декомпозиция как в DOCS/01.
2. Оракул независим от инструмента: оракул пишет Python по тексту SPEC,
   инструмент — машинный код. Совпадение = два независимых свидетеля.
3. Расхождение оракула и инструмента — не «победа» одного из них,
   а находка: разбирается по исходнику модуля и SPEC; правится либо
   оракул (если он понял SPEC неверно), либо заводится задача на
   исправление инструмента (этап, карточка, тест).
4. Эмулятор валидируется только на документированных эталонах TESTS/
   и VERIFY.md; «подгонка под код» запрещена.
5. `ai/` — частная зона ИИ-разработчика (журнал сессий, планы,
   черновики диагностики); системные файлы её не читают.

## CI (GitHub Actions)

`.github/workflows/verify.yml` запускает батарею автоматически при
каждом пуше — как автоколебимая лаборатория. CI относится к внешним
приборам (как и сам LAB): система UNIVERSAL от него не зависит.
Красная проверка CI = незавершённое изменение (правило DOCS/04).
